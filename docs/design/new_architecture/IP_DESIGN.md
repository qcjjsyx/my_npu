# 多精度 MAC 新架构 IP 设计

状态日期：2026-11-12。本文是按计算流程、按功能级编排的完整设计稿，待用户整体审核；不是已完成的 RTL 实现说明。既有数值与资源决定来自[设计决策](../../project/decisions.md)，剩余连接、编码、物理流水和接口细节按本轮授权补齐。本文不自动代表审核通过，也不授权开始 RTL。

## 1. 设计目标、边界与总体数据流

### 1.1 目标与实现范围

面向 LLM 推理，重点支持 FP8/FP4 及 MX，研究多格式乘法资源复用与有限精度累加。设计目标为单输出实际点积长度不超过16384项；外部补零不计入实际长度。输入启动间隔II=1适用于合法多上下文交错更新，不要求单一输出每拍更新。不预设500 MHz，后续报告实际综合与时序结果。

实现对象是独立输入转换器和 MAC 核心。转换器不例化在MAC内，二者不物理连接，各自测试；MAC测试直接提供转换后的字段。核心止于ACC状态寄存器及完成状态读取，不实现FP32/INT32转换、结果FIFO、中途状态导出/恢复、外部初值装载、量化或scale生成。外部负责数据供给、MX块对齐、尾段补零、上下文调度与结果消费，不要求核心实现算子形状处理或SRAM管理。

所有新事务从零开始，未完成事务可以暂停供数，状态留在原槽，之后继续同一累加序列。最终读取不重新舍入。后续硬件使用Verilog，旧[IP设计](../IP_Design.md)和[RTL说明](../RTL_Design.md)仅用于旧基线参考。

### 1.2 功能级与模式


K为每次输入每组的项数，G为独立输出组数。FP8支持E4M3FN、E5M2及双向交叉组合，转换后无需MAC源格式标签；其他格式只支持同格式相乘。不支持跨整数位宽、FP16×BF16、浮点×整数或单侧MX混用。

### 1.3 顶层端口与输入约束

全部端口以clk上升沿为时序基准，rst_n为低有效同步复位。Verilog顶层使用平坦向量，数组只作为内部表示。

| 端口 | 方向 | 宽度 | 定义 |
|---|---|---:|---|
| clk / rst_n | 输入 | 各1 | 时钟/同步复位 |
| i_a_fields / i_b_fields | 输入 | 各352 | 16个22-bit槽，槽j为[22j+21:22j] |
| i_mode / i_mx | 输入 | 3 / 1 | 上表模式及双侧MX使能 |
| i_scale_a / i_scale_b | 输入 | 各16 | 低字节g0、高字节g1的原始E8M0 |
| i_ctx / i_first / i_last / i_valid | 输入 | 2 / 1 / 1 / 1 | 配对上下文编号、首次、末次、有效 |
| o_ctx_free / o_ctx_done | 输出 | 各3 | 逐槽空闲/完成位图 |
| i_result_ctx / i_result_ready | 输入 | 2 / 1 | 指定读取槽/接收确认 |
| o_result_valid | 输出 | 1 | 所选槽已完成 |
| o_state0 / o_state1 | 输出 | 各51 | 完整数值状态，见第8章 |
| o_result_mode / o_result_mx | 输出 | 3 / 1 | 所选完成状态模式 |
| o_pipe_empty | 输出 | 1 | 计算流水全部valid为0，不包含已存上下文 |

正常计算无i_ready。非复位边沿i_valid=1即接收一份合法输入；外部不得用重复保持valid的方式等待接收。i_valid=0时数据和metadata不解释。同ctx输入边沿间隔至少3拍，模式切换要求该边沿之前全部槽空闲且o_pipe_empty=1。非法调度由验证环境断言，不增加冲突调度器或错误恢复路径。

整数输入为对称补码范围：INT4[-7,7]、INT8[-127,127]、INT16[-32767,32767]，最小负码非法。MX scale为0x00…0xFE，0xFF非法；指数s=unsigned(scale)−127，0x00为2^-127。非MX忽略scale，G=1忽略高字节；建议驱动0。有效MX每组的K项不跨A/B任一侧32元素块，块边界由外部对齐。MXFP8/MXINT8同块两份dot16分别携带相同scale，尾段可在最后必要的一份内补零并last，不要求额外补齐一整块。G=2两组scale与数据独立。

## 2. 独立输入转换

### 2.1 接口、编码与寄存器

一份转换器逻辑的端口为clk、rst_n、i_raw[15:0]、i_fmt[2:0]、i_valid和o_fields[21:0]、o_valid。fmt编码依次为0=FP4、1=E4M3FN、2=E5M2、3=BF16、4=FP16、5=INT4、6=INT8、7=INT16；fmt与MAC mode是不同编码。

采用组合解码后一级输出寄存器：在采样i_valid/i_raw/i_fmt的上升沿更新o_fields和o_valid，输出在该边沿后可用；这是一个寄存器级，外部同步接收者最早在下一边沿采样。无ready，连续有效输入每拍一份；气泡令o_valid=0并保持数据寄存器。复位清o_valid和o_fields。此延迟不计入MAC核心周期。

raw的低位先放g0：FP4和INT4依次为bits[3:0]=g0p0、[7:4]=g0p1、[11:8]=g1p0、[15:12]=g1p1；FP8/INT8低字节g0、高字节g1；BF16/FP16/INT16整个字为单元素。

### 2.2 有限化和精确保值重编码

先按源格式分类，再生成补码系数。NaN映射零；具有Inf编码的格式将±Inf映射为对应带符号最大有限值；±0统一零；subnormal保留hidden=0、有效指数取1，不做FTZ。E4M3采用E4M3FN，exp=15且frac=7才是NaN，其余exp=15编码仍有限；FP4 E2M1所有编码有限。整数非法最小负码不钳位。

| 格式 | 解码及数值恒等式 | 最终计算字段 |
|---|---|---|
| FP8 | m=±(hidden·8+frac3)，E4M3FN的Eu=Eeff+8，E5M2的Eu=Eeff且frac3=frac2<<1；x=m·2^(Eu−18)。Q=Eu>>2，M=m<<Eu[1:0] | M signed8、Q unsigned3；x=M·2^(4Q−18) |
| FP16 | m=±(hidden·1024+frac)，x=m·2^(E−25)；Q=E>>2，M=m<<E[1:0] | M signed15、Q unsigned3；x=M·2^(4Q−25) |
| BF16 | m=±(hidden·128+frac)，x=m·2^(E−134) | m signed9、E unsigned8 |
| FP4 | q=2x；正幅值编码0…7对应q=0,1,2,3,4,6,8,12；符号位决定正负 | q signed5 |
| INT4/8/16 | 补码整数q原值；INT4符号扩展到5位 | q signed5/8/16 |

移位前先扩位。FP8两种格式最大|M|分别120、112，FP16最大16376，BF16最大|m|=255。元素零统一输出零系数和零指数，不能把零指数自动解释为零元素。MXINT8转换器仍输出整数码q；q·2^-6及双侧乘积的2^-12权重由MAC处理。

### 2.3 22-bit bundle布局

| 模式 | 布局（未用高位置0） |
|---|---|
| FP8 | [10:0]={Q0[2:0],M0[7:0]}；[21:11]={Q1,M1} |
| FP4/INT4 | [4:0]=g0p0；[9:5]=g0p1；[14:10]=g1p0；[19:15]=g1p1 |
| INT8 | [7:0]=g0；[15:8]=g1 |
| BF16 | [16:0]={E[7:0],m[8:0]} |
| FP16 | [17:0]={Q[2:0],M[14:0]} |
| INT16 | [15:0]=q |

转换器只处理一个raw字，不承担16前端并行供数或MX scale生成。MAC的FP8交叉组合由A/B分别转换为统一M/Q实现。

## 3. 共享乘法与完整乘积形成

### 3.1 资源映射

每个物理前端配置 2 颗 signed9×signed9（W0/W1）和 2 颗 signed5×signed5（S0/S1）。16 前端共 32 颗宽块、32 颗小块。

| 模式 | W0 | W1 | S0 | S1 | 完整乘积/前端（对） | K/G |
|---|---|---|---|---|---|---:|
| FP4 | g0p0 | g1p0 | g0p1 | g1p1 | 4 | 32/2 |
| INT4 | g0p0 | g1p0 | g0p1 | g1p1 | 4 | 32/2 |
| FP8 | g0 | g1 | 空闲 | 空闲 | 2 | 16/2 |
| INT8 | g0 | g1 | 空闲 | 空闲 | 2 | 16/2 |
| BF16 | g0 | 空闲 | 空闲 | 空闲 | 1 | 16/1 |
| FP16 | 偶前端 p00，奇前端 p10 | 偶前端 p01，奇前端 p11 | 空闲 | 空闲 | 1/对 | 8/1 |
| INT16 | 偶前端 p00，奇前端 p10 | 偶前端 p01，奇前端 p11 | 空闲 | 空闲 | 1/对 | 8/1 |

- FP4/INT4 使用全部四颗块；W0/S0 固定 g0，W1/S1 固定 g1。
- BF16 只使用 W0，保持一组 dot16；不启用 32 乘积/拍或 G=2。
- FP16/INT16 每对前端同拍形成四部分积；W1 在该模式下不再表示 group1，S0/S1 空闲。FP16 低段 unsigned8、高段 signed7；INT16 低段 unsigned8、高段 signed8；低段零扩展，高段符号扩展。
- FP16/INT16 完整重构：`P=p00+2^8×(p01+p10)+2^16×p11`；FP16 用 signed30，INT16 用 signed32。偶前端计算 p00/p01，奇前端计算 p10/p11；移位前扩展，四部分积同拍形成，不使用两拍 phase。
- 前端输出：FP8 为 P signed16+T unsigned4；BF16 为 P' signed21+Q unsigned7；FP16 为 P signed30+T unsigned4；INT16 为 P signed32；FP4 为 P signed9；INT4 为 P signed8；INT8 为 P signed16。`T/Q=0` 不代表零乘积，零判定使用 `P!=0`。


### 3.2 输入槽到物理前端的连接

FP4/INT4的前端j处理g0和g1各自第2j、2j+1项；FP8/INT8的前端j处理两组各第j项；BF16的前端j处理g0第j项。

FP16/INT16第j个完整元素（j=0…7）只从输入槽2j取得A/B完整bundle。槽2j+1未使用，硬件忽略其位值，供数建议置0，不要求重复传送。R_IN中的偶槽完整A/B广播给物理前端2j与2j+1：

| 物理块 | A操作数 | B操作数 | 输出 |
|---|---|---|---|
| 前端2j W0 | aL零扩展到9位 | bL零扩展到9位 | p00 |
| 前端2j W1 | aL零扩展 | bH符号扩展 | p01 |
| 前端2j+1 W0 | aH符号扩展 | bL零扩展 | p10 |
| 前端2j+1 W1 | aH符号扩展 | bH符号扩展 | p11 |

FP16先把signed15的M拆成unsigned8低段和signed7高段；INT16拆为unsigned8低段和signed8高段。FP16每对只从偶槽提取QA、QB并生成一次T=QA+QB，与四部分积共用同一流水metadata；不能从未用奇槽取得指数。跨前端分发只形成一个完整乘积，不是跨group共享输入。

### 3.3 部分积重构、BF16折叠和物理切分

R_MUL记录32个signed18宽乘积、32个signed10小乘积及指数信息；非活动块输入置0，不另加时钟门控。原生短乘积缩窄只删除冗余符号位。

重构级用有符号34-bit临时域执行两层合并：U=sext(p00)+(sext(p01)<<8)，V=(sext(p10)<<8)+(sext(p11)<<16)，P=U+V；FP16截取signed30、INT16截取signed32前须确认被删位为冗余符号扩展。34位临时域覆盖中间项，最终数值仍为既定完整乘积。这里的加法结构不改变四部分积公式。

BF16在R_MUL后的同一功能阶段执行T=EA+EB（unsigned9），r=T[1:0]、Q=T>>2（unsigned7），P'=sext21(P)<<r。P=0时P'=Q=0。FP8、FP16的乘积指数和使用unsigned4；R_PROD将其零扩展为7位粗指数。其他模式经过同一寄存器边界，不缩短延迟。

R_PROD的逻辑有效载荷：FP4为64×signed9、INT4为64×signed8、FP8为32×(signed16+unsigned7)、BF16为16×(signed21+unsigned7)、FP16为8×(signed30+unsigned7)、INT8为32×signed16、INT16为8×signed32。物理槽和模式路由如上，允许共享寄存器位，但不得改变元素顺序。

## 4. 每组非零MAX与局部对阶

### 4.1 数值合同

浮点各项写成A_i·2^(4Q_i−b)。FP8的A为完整乘积、b=36；FP16 b=50；BF16为postfold后的P'、b=268。每组单独求Q*=max(Q_i | A_i≠0)，然后

```text
d_i = 4·(Q*−Q_i)
n_i = floor(A_i·2^(F−d_i))
N = Σ n_i
e_loc = 4Q*−b−F
```

| 模式 | A容器 | F | n_i容器 | 项数 | N容器 |
|---|---:|---:|---:|---:|---:|
| FP8 | signed16 | 16 | signed32 | 16 | signed36 |
| BF16 | signed21 | 11 | signed32 | 16 | signed36 |
| FP16 | signed30 | 8 | signed38 | 8 | signed41 |

先在指定容器拼接F个低零位，再算术右移。floor是向负无穷取整，不能把大距离负数移位统一变成0；移位距离大于等于容器宽度时结果为符号填充（正数0，负数−1）。本级不做逐项RNE，不存用于局部舍入的GRS。零乘积直接输出0，无需计算其指数差；全零组Q*=0并最终规范N=e_loc=h=0。

### 4.2 MAX和移位器资源

采用两棵16输入的7-bit非零MAX平衡比较树，叶子带nz标记，合并时优先保留有效叶子，再比较粗指数。A组用于FP8 g0、BF16 g0、FP16 g0；B组用于FP8 g1。FP16只使用A组前8叶，其余nz=0。非对阶模式两树不使能，Q*占位置0。R_MAX同时保存完整乘积及每组Q*/any_nonzero，避免后续事务覆盖所需指数。

移位器A组为8个38-bit加8个32-bit，B组为16个32-bit，共32条通路。A组前8条在FP8/BF16模式将32-bit对阶输入高位符号扩展为38位再移位，结果低32位与原32-bit算术移位一致；FP16使用全部38位结果。其余A/B通路服务相应FP8/BF16元素。这样只扩宽8条必要通路，不另设8条独立FP16移位器。

Q*−Q_i用7-bit无符号有效差，左移2位形成9-bit距离，范围0…508；零叶子旁路后才计算距离。按实际移位器宽度处理超宽距离，符号填充不属于数值饱和。FP4/普通整数不经过对阶算术，直接路由其乘积，所有模式仍在R_ALIGN形成树输入。

## 5. 局部归约与贡献记录

### 5.1 两棵平衡树

采用2棵16输入、signed32输入、signed36输出的二输入平衡加法树，再加1个41-bit最终加法器。每棵树四层位宽依次33、34、35、36，前两层后置R_TREE_LO（每树4×34），后两层后置R_TREE_HI（每树1×36）。每个加数先符号扩展至本层宽度，树内无截断或舍入。

| 模式 | TreeA输入 | TreeB输入 | 41-bit最终级 |
|---|---|---|---|
| FP8/INT8 | g0的16项 | g1的16项 | 两个树和分别旁路并符号扩展 |
| BF16 | g0的16项 | 0 | A树和旁路 |
| INT16 | 8个完整signed32乘积+8个0 | 0 | A树和旁路 |
| FP16 | 8个CL+8个0 | 8个CH+8个0 | 低和+(高和<<19) |
| FP4/INT4 | packed p0/p2 | packed p1/p3 | 两树和相加、切分及偏置修正 |

两树各15次二输入加法，末级一次，共31次结构加法；不包括完整乘积重构和ACC，也不代表面积、功耗或时序结论。末级旁路保留R_SUM寄存器，所有模式延迟一致。

### 5.2 FP16 19/19拆分

对阶结果C为signed38，CL=C[18:0]按unsigned19，CH=C[37:19]按signed19，恒等式C=CL+2^19·CH。CL零扩展到32-bit树输入，CH符号扩展到32-bit；两树各8个有效项，其余8项置0。

ΣCL为unsigned22，ΣCH为signed22。R_TREE_HI的36-bit容器保留其精确和；重构前ΣCL零扩展到41位，ΣCH符号扩展到41位后左移19位，N=ΣCL+(ΣCH<<19)。低和不能缩回19位，其自然进位由41-bit最终加法器吸收。

### 5.3 FP4/INT4 offset-binary packing

记 `p0=W0(g0)`、`p1=S0(g0)`、`p2=W1(g1)`、`p3=S1(g1)`：

```text
L=9（FP4）或8（INT4），W=L+5，β=2^(L-1)
p0o=p0^β，p1o=p1^β
A_i={p2_i,5'b0,p0o_i}
B_i={p3_i,5'b0,p1o_i}
S=ΣA_i+ΣB_i
g0=signed(S[W-1:0]^2^(W-1))
g1=signed(S[W+L+4:W])
```

低场加 β 后为非负数，32 项偏置总和为 `32β=2^(W-1)`，由最终低场 MSB 取反精确消除；中间 5 个 0 位是求和增长位。packed word 宽度为 `L+W`，按高场 `p2/p3` 的符号扩展到 32-bit 树输入；树输出 36-bit。不能直接用补码 `{p2,5'b0,p0}`，也不能只向 guard 位做符号扩展，否则负乘积的偏移/借位会污染高场。

| 模式 | L | β | W | packed word | Tree 输出 | 最终 S | g0/g1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| FP4 | 9 | 256 | 14 | 23 | 27 | 28 | 14/14 |
| INT4 | 8 | 128 | 13 | 21 | 25 | 26 | 13/13 |

INT4 的 g0/g1 逻辑 N 为 12 bit，13-bit 字段含一个冗余符号位。


### 5.4 R_SUM贡献记录

每个group一条固定槽记录，g0/g1由物理槽索引区分，不另传group位：

| 字段 | 宽度 | 含义 |
|---|---:|---|
| N | signed41 | 局部精确整数和 |
| e_loc | signed10 | 局部最低位指数，不含MX scale |
| h | signed9 | 两侧scale指数之和，非MX为0 |
| mode/mx/ctx/first/last | 3/1/2/1/1 | 两组共用的事务metadata |
| valid | 1 | 两组共用有效位；G由mode推导 |

N逻辑位宽依次为FP4 14、INT4 12、FP8 36、INT8 19、BF16 36、FP16 41、INT16 34，统一符号扩展41位。非零浮点贡献的e_loc：FP8=4Q*−52、BF16=4Q*−279、FP16=4Q*−58、FP4=−2、MXINT8=−12。普通整数e_loc=h=0，仅使用N。

任一组N=0都在R_SUM规范该组N=e_loc=h=0；不取消该组有效贡献或last。G=1的g1槽全部数据置0、ACC1不使能。41-bit最终加法器在FP4/INT4与FP16之间复用；FP8/BF16/普通INT8/INT16没有这次数值加法。

## 6. MX缩放与贡献无损规格化

R_IN将每个有效MX scale按9-bit有符号域解码，sA/sB∈[-127,127]，h=sA+sB∈[-254,254]，只保存每组signed9的h并随流水推进；非MX为0。因为局部归约内scale一致，h无需进入乘积或MAX。h只在本级加一次。

浮点及全部MX贡献v=N·2^e，e=e_loc+h。N≠0时k=floor(log2|N|)，生成M_v=N<<(39−k)，H_v=e+k；N=0输出M_v=H_v=0。绝对值只用于前导位检测，M_v保留补码符号。指数计算在signed11域完成，再按已证明范围写入signed10，禁止先在窄域相加回绕。

合法FP16局部贡献最大|N|=8·16376²·2^8=549219074048<2^39，是这些路径中的最大者，因此k≤38，规格化仅需左移，不独立舍入。|N|<2^40是模型通用必要条件，不能把signed41容器全部位模式当合法输入。

本级配置两路规格化逻辑以承接G=2，两路输出R_MX：每组M_v signed41、H_v signed10、I_v signed45；浮点只使用M_v/H_v并将I_v置0，普通整数I_v=sext45(N)，M_v/H_v置0。R_MX共用metadata和valid；普通整数保留本物理级，旁路指数与规格化算术。

scale作用于新贡献，不能重新缩放旧状态。普通FP4同样使用浮点状态；MXINT8按N·2^(h−12)进入浮点状态，普通INT8不使用该权重。

## 7. 双路累加数据通路

### 7.1 状态表示和范围

每条ACC有3个51-bit状态槽。浮点保存[50:41]=H、[40:0]=M；普通整数保存低45位精确累加值，高6位符号扩展。每槽的数值只在S3有效写回时更新，事务first通过旧值mux选择零，不需要先清数值寄存器。

浮点C=M·2^(H−39)，非零2^39≤|M|<2^40，M用signed41，H用signed10；不使用M=−2^40，零为M=H=0。每份贡献按原顺序执行C_next=RNE40(C_old+v)，没有配对、预舍入或分链合并。

普通整数C_next=C_old+N精确执行。L≤16384、输入对称域下|C|≤16384·(2^(w−1)−1)²，INT4/8/16分别需要signed21/29/45，统一signed45即可，不逐次饱和。浮点主和最多需要44位，故两类共用45-bit加法器，但不共用同一种数值语义。

合法链的浮点H范围为[-346,306]。下界来自每步规格化最多降低40位且最大操作数指数至少−306；σ=41的负端情况伴随重规格化c=1。上界包括每次RNE的累计影响：保守取更新次数n≤2^14、单贡献|v|<2^292，有|C_n|≤(1+2^-39)^n·Σ|v_i|≤(1+2^-24)·2^306<2^307。该范围支持内部无FTZ、饱和、Inf/NaN；范围在验证环境断言，不设置硬件钳位或恢复入口。

### 7.2 S1：组合读与补码对阶

由R_MX.ctx组合选择状态，first强制旧值零。零旧值或零新贡献直接选另一方作为最终数值旁路；两者均零输出规范零。旁路结果随S1/S2寄存器等待S3写回，不能提前完成；零的H=0不参与指数比较。

两侧非零时令H_a=max(H_old,H_v)，d=H_a−H_b，a/b为对应M。相等时旧值为a。d用signed11非负值（0…1023）。取工作位权u0=2^(H_a−41)：

```text
A = 4a
B = floor((4b)·2^(-d))
τ = (4b)·2^(-d) − B，0≤τ<1
C_old+v = (A+B+τ)·u0
```

先将M扩位到43位再左移2，B按43-bit补码算术右移d；sticky为被丢弃位的OR。d≥43时B全部符号填充，sticky为原43位全部位的OR（非零操作数为1），不可把超大移位距离截成低几位。d≤2时被移出的低位全为0，τ=0。

S1记录A/B各signed45（43位高位符号扩展）、H_a signed10、tail_nonzero=τ≠0、bypass和bypass_state[50:0]，以及共用metadata/valid。普通整数S1记录旧signed45与I_v，其他算术控制置0。

### 7.3 S2：共享加法

每路执行signed45 T=A+B并记录T、H_a、tail_nonzero和旁路信息。浮点|T|≤2^43−8，最高位为冗余符号位；整数结果在signed45范围内。sticky不作为一个定值位加入主加法器，它只表示向下取整主值之下的非负余量。

### 7.4 S3：规格化、加后RNE与直接写回

普通整数直接写回T并符号扩展到51位。浮点旁路直接写回bypass_state；其余按以下顺序执行：

1. T=0输出M=H=0；合法输入下此时τ=0。
2. t取T中与符号位不同的最高位位置：正数最高1，负数最高0。σ=41−t，范围[-1,41]。不能用floor(log2|T|)替换负数规则。
3. σ≥0时T'=T<<σ；σ=−1时T'=T算术右移1，并将移出bit0并入sticky。移位先在足够的45-bit域完成，合法T'可精确保存为signed43。
4. M_pre=T'算术右移2（signed41），G=T'[1]、R=T'[0]、S=tail_nonzero OR 右移移出位。inc=G AND (R OR S OR M_pre[0])；M_r=sext42(M_pre)+inc。
5. 若M_r=±2^40，令M=M_r算术右移1、c=1；否则M=M_r、c=0。正向进位与负端−2^40均必须处理。
6. H_next=H_a−σ+c在signed11域计算，合法结果存signed10。直接写回状态寄存器，不加结果暂存级。last在同一边沿置done。

负数算术右移为向负无穷取整，例如−2.5=−3+0.5；RNE的inc仍是加一，平局按保留整数奇偶选择。负精确二次幂的t比幅值最高位低一位，会先得到M_pre=−2^40，由负端重规格化修正，不能省略。

2个真实低位加sticky的依据：τ>0时d≥3，|T|≥2^41−2^(42−d)>2^40，故t≥40、σ≤1。左移最多一位时G仍精确；余量可能改变R，但τ>0使S=1，不影响inc正确性。τ=0时真实低位精确，可用于深度抵消。d=3、σ=1以及T=−2、σ=41均是必须验证的边界。完整模型依据见第10章。

## 8. 上下文控制与完成状态读取

### 8.1 生命周期与模式

ctx为2-bit，0/1/2合法。槽c对应ACC0[c]和ACC1[c]，G=1仅使用ACC0。每槽2-bit生命周期：00=FREE，01=ACTIVE，10=CLOSING，11=DONE。G=2共用控制状态，但数值分别存储。

| 当前状态/事件 | 边沿动作 |
|---|---|
| FREE接收first=1,last=0 | ACTIVE |
| FREE接收first=last=1 | CLOSING |
| ACTIVE接收first=0,last=0 | 保持ACTIVE |
| ACTIVE接收last=1 | CLOSING，禁止后续追加 |
| CLOSING的last到达S3 | 写回最终状态并转DONE |
| DONE被结果读取握手接收 | FREE |

禁止其他输入组合，外部保证并由验证环境断言。不因为旧的非last在CLOSING期间写回而拒绝写回：它们是last之前已接收的合法贡献。first/last随流水进入ACC，不能用入口当前控制替代旧事务metadata。

使用一份batch_mode[2:0]、batch_mx保存当前批次模式。在全部槽FREE且流水为空时接收first，锁存新模式；只要任一槽占用，所有输入必须与批次模式相同。每拍仍传mode/mx以使级间关联显式。所有槽释放后方可切换；读出侧使用锁存批次模式，不会因新输入修改未提交状态的解释。

### 8.2 结果读取与无效行为

o_ctx_free/done由生命周期解码。i_result_ctx选择DONE槽时o_result_valid=1，组合mux选择其两路状态及批次模式；G=1将o_state1置0。选择非DONE槽或编号3时o_result_valid=0、两路状态及输出mode/mx全置0，不泄露未完成或未初始化寄存器内容；无效读取ready不释放任何槽。允许编号3作为无选择占位，但不允许有效计算输入ctx=3。

在o_result_valid AND i_result_ready的边沿外部采样并释放所选槽，G=2原子交接两份状态；无内部仲裁或固定完成顺序，外部可任选完成槽。选中编号不变且未握手时数据保持；改变编号会改变输出，这是一种指定地址读取协议，不是自主选队首的FIFO协议。

释放边沿禁止同时向同一槽发first，下一边沿才可复用。不同槽可在同一边沿发生读取释放、输入接收和S3写回；各槽分别更新。last写回边沿之前done仍为0，不能在该边沿提前读取，最早下一边沿接收。

### 8.3 复位、暂停与容量边界

同步复位优先于输入、写回和结果接收：清所有计算valid、将三槽置FREE、批次mode/mx清0。数值状态与流水数据寄存器无需复位，因无效读取输出0、first旧值选择零且valid禁止陈旧写回。独立转换器按第2章复位。复位中止所有在途和已完成未取走事务，不承诺复位后续算；外部需重新发first。

暂停仅需i_valid=0，所有在途valid继续推进，已写回状态保持；外部之后以原ctx、first=0续算。无暂停/恢复命令、状态写入端口或额外ready。读取最终状态后可由外部保存到SRAM，但不能再将其导回本MAC继续计算。

三个槽是三个同时占用的事务（G=2共六个独立输出值）。外部不读取完成状态时这些槽不能复用，但其他合法在途更新不冻结。II=1针对三槽交错的持续贡献阶段：若每事务只有一份贡献，三个first/last接收后必须等完成读取，不能宣称任意短事务连续每拍启动。外部接收速度也会影响新事务启动吞吐。

## 9. 物理流水、记录与周期合同

### 9.1 各级寄存器

所有记录共用事务meta={mode[2:0],mx,ctx[1:0],first,last}共8位，加一个valid；G由mode推导。级内不设置ready或全局冻结。每拍valid无条件前移，data在对应输入valid时更新，气泡数据可保持；任何状态写入以有效位门控。g0/g1数据槽的索引就是group，不需额外编码。

| 接收边沿相对E0 | 寄存器/动作 | 数值与必要关联字段 |
|---|---|---|
| E0 | R_IN | A/B各16×22；h0/h1各signed9；meta/valid |
| E1 | R_MUL | 32×signed18宽乘积、32×signed10小乘积；每组/元素指数（FP8为4、BF16为9、FP16配对为4）；h、meta/valid |
| E2 | R_PROD | 第3.3节各模式完整乘积及7-bit粗指数；h、meta/valid |
| E3 | R_MAX | R_PROD载荷；两组Q* unsigned7及any_nonzero；h、meta/valid |
| E4 | R_ALIGN | 两树各16×signed32输入；两组e_loc signed10、h signed9；meta/valid |
| E5 | R_TREE_LO | 每树4×signed34；e_loc/h；meta/valid |
| E6 | R_TREE_HI | 每树signed36；e_loc/h；meta/valid |
| E7 | R_SUM | 两组N signed41、e_loc signed10、h signed9，零规范；meta/valid |
| E8 | R_MX | 两组M_v41/H_v10/I_v45；meta/valid |
| E9 | R_ACC1 | 每路A45/B45/H_a10/tail1/bypass1/bypass_state51；meta/valid |
| E10 | R_ACC2 | 每路T45/H_a10/tail1/bypass1/bypass_state51；meta/valid |
| E11 | 状态写回 | 直接更新ctx状态，last时置DONE；无新增计算valid寄存器 |

R_ALIGN负责对阶、树输入路由/packing及e_loc生成；R_SUM负责最终重构与零规范。FP16、BF16、整数、MX均通过相同边界；未用槽确定置0，不依赖未初始化位进行运算。R_MUL/R_PROD的模式专用数组可采用独立内部寄存器名称，公共物理位复用只允许保持本表的逻辑记录，不要求先冻结门级优化。

E0为顶层采样输入的边沿；E11之后状态更新可见，入口至写回为11个完整时钟间隔。计算流水共有R_IN至R_ACC2的11个valid寄存器，另有状态写回终点。该定义避免将“寄存器级数”“输入后经过的边沿数”混为一个延迟数字。若该份是last，最早E12读取接收，最早E13在入口复用该槽。

### 9.2 D=3的状态反馈

令A0在E9采样S1对阶结果、E10采样S2和、E11写回；A1在入口E3接收，对应E12采样S1。E11写回后，A1在E11至E12组合读取新状态并完成对阶。没有同边沿新值穿透或旁路依赖。

| 边沿 | S1结果采样 | S2结果采样 | S3写回 |
|---|---|---|---|
| E9 | A0 | — | — |
| E10 | B0 | A0 | — |
| E11 | C0 | B0 | A0 |
| E12 | A1 | C0 | B0 |
| E13 | B1 | A1 | C0 |
| E14 | C1 | B1 | A1 |

同ctx若提前到E11采样S1，将用不到E11才写回的值，因此最小间隔为3拍。只有一个活动输出时输入A0、气泡、气泡、A1；两个时A0、B0、气泡、A1、B1、气泡。各模式前向等延迟保证入口和S1间隔一致。G=2两条通路同时遵循此表，G=1禁止ACC1写回。

### 9.3 气泡、阻塞与排空

o_pipe_empty为R_IN至R_ACC2全部valid之OR取反，不计上下文占用。最后一次输入在E0接收且之后无新输入时，E11写回后o_pipe_empty变为1。流水为空时可仍有ACTIVE或DONE槽；不能据此清状态或切模式，模式切换还需o_ctx_free=3'b111。

外部result_ready=0只使DONE槽保持，不传播到计算流水。无输入valid时元数据气泡与数据一起推进，不会将后来first/last套到较早数值上。初始空流水的输入边沿之前o_pipe_empty可能为1，这不意味着该边沿不能接收输入；排空条件用于观察当前寄存器占用，须结合是否继续供数判断。

## 10. 验证目标、证据与审核边界

### 10.1 功能验收与精度评价

功能验收要求新RTL逐位符合已定数值合同和本周期协议。数值精度评价从入口映射后的编码及scale出发，比较精确数学点积与局部截断、RNE40状态、外部最终转换之间的差异。统一精度阈值尚未由用户确定，不自行继承旧阈值；它不是接口或逐位功能验证的前置条件。

外部参考转换：普通整数最终转INT32并在末次转换饱和；浮点及全部MX转FP32，RNE、有限值饱和、渐进下溢，精确零为+0，非零舍入为零保留符号。这些是评价口径，不在本MAC内实现。
