## 2. 已确定的实验语义

- 输入格式：FP8 E4M3 和 TF32。
- 输入并行度固定为 16；B 表示累加更新次数，K=16B 自动推导。
- 乘积保留完整有效位，不做乘积舍入或规格化；乘积指数采用输入指数之和。
- 每个 block 的 16 个乘积在有限 W 窗口逐项对阶，再用足够宽的整数加法求和。
- 累加状态为 FP32，初始化为 +0。
- **部分和不预先舍入为 FP32，不压缩成另一个有限精度浮点格式。**
- 完整部分和与当前 FP32 状态相加，最后仅进行一次 RNE 舍入到 FP32。
- W 只控制 16 个乘积之间的对阶精度。累加器不作为第 17 项进入该 W 窗口；部分和与累加器的对阶也不引入第二个实验窗口。
- 不实现历史 e30、accumulator-aware、17-term fixed-window fused 或 BF16 路径。只预留清晰接口。

默认对阶舍入采用 RNE ties-to-even；这是可替换策略，不等于已经确认某个真实硬件采用 RNE。FP32 更新必须正确舍入，支持渐进下溢；输入的 FTZ 规则与输出渐进下溢分别记录。

### 2.1 编码和窗口的明确约定

FP8：E4M3，bias=7，正常有效数整数为 8+fraction；exp=15、frac=7 为 NaN，其他 exp=15 编码按有限值处理。输入 exp=0 按零处理，采样器默认不生成该类编码。

TF32：1 符号位、8 指数位、10 fraction 位，bias=127，正常有效数整数为 1024+fraction。内部可以采用紧凑 19 位编码，但接口必须明确；不能把它误当成 FP32 原始 bit pattern。输入 exp=0 按零处理，exp=255 为特殊值并排除。

对乘积 `signed_sig * 2**product_lsb`，令 C 为两输入 raw exponent 之和：

| 格式 | product_lsb | 窗口 LSB 指数 |
|---|---|---|
| FP8 E4M3 | C-20 | Cmax-14-W |
| TF32 | C-274 | Cmax-254-W |

Cmax 取当前 block 非零乘积的最大 C。全部为零时按明确的零路径处理。
每项转换到共同窗口整数单位，右移时执行有符号 RNE。W 是相对于公共指数基准的小数位数，**不是总位宽**。16 项普通窗口使用 W+7 位有符号整数容器；证明/测试其范围，并检测越界，不默默 wrap 或饱和。

这些常数放在格式适配器中，通用 reducer 不写格式分支。

### 2.2 单次 FP32 更新

精确数统一表达为 `Dyadic(integer, exponent)`，值为 integer × 2**exponent。

对 block b：

```
s_b = exact_sum(exact_products_b)
q_b = exact_sum(aligned_and_rounded_products_b)
a_b = RN32(exact_value(a_(b-1)) + q_b)
r_b = RN32(exact_value(r_(b-1)) + s_b)
```

a 是候选状态，r 是无窗口损失的路径参考，二者各自从零递推。必须直接从精确 dyadic 和舍入到 FP32，不能经 binary64 或先把 q_b/s_b 转为 FP32。

即使换算为规格化形式，也必须保留部分和的全部有效位，不引入可变 P 精度。

## 3. 参考、误差和指标

S_B = sum(s_b) 为完整 K 项点积的数学精确和，不预先转 FP32。
L1_B = sum(abs(exact_product_i))，从整数/dyadic 精确累计。

保存三个明确命名的比较：

| 名称 | 实际值 | 参考值 |
|---|---|---|
| total | a_B | S_B |
| window_effect | a_B | r_B |
| fp32_baseline | r_B | S_B |

window_effect 是有限 W 对最终输出的影响，包含舍入传播，不能命名为纯局部对阶误差。fp32_baseline 是参考基线，不是候选总误差的严格下界。

每个比较计算：p99_abs_error、p99_eta_l1、relative_l2、rmse_abs_error、max_abs_error、mean_signed_error、match_rate。可额外保存 p50/p90，但不必实现 ULP 主流程。

- eta_l1 每样本为 abs(error)/L1_B，再计算分位数。
- relative_l2 为 sqrt(sum(error²)/sum(reference²))；window_effect 的 reference 为 r_B，另外两项为 S_B。
- reference RMS 单独保存，用于解释尺度和抵消。
- p99 采用明确记录的线性插值定义（位置为 (N-1)*0.99）；不同 seed 合并逐样本结果后计算，不平均各 seed 的 p99。
- match 通过精确数值比较计算，不能因转换成 binary64 而误判。
- 分母全零时：误差也为零返回 0，否则指标标记为未定义并记录原因。禁止用 `denominator or 1` 伪造有限结果。
- 指标转成常规浮点只发生在精确误差已得到之后。聚合避免明显溢出/下溢；JSON 不写裸 NaN/Infinity，未定义用 null 加状态。

同时保存两个有符号阶段误差：

```
E_align = sum(q_b - s_b)
delta_b = a_b - (a_(b-1) + q_b)
E_acc   = sum(delta_b)
```

对有限数必须逐样本精确满足 `a_B-S_B = E_align+E_acc`。阶段统计报告均值和 RMS；不要把阶段绝对值、p99、RMS 相加当总误差。

事件区分：固定窗口 overflow、非有限 FP32 结果、unexpected_zero、对阶置零、局部更新被吸收。unexpected_zero 定义为更新后 a_b=0 且 r_b!=0，是诊断，不默认一票否决整个方案；越界与非有限结果必须明确标记为不可作普通精度统计的运行/单元格。按实际检查位置区分计数，不能将 FP32 溢出归为窗口溢出。

事件按前缀累计，同时记录最终端点事件；各 B 快照的累计计数不能再相加。统计错误或非有限样本不能静默丢弃。

## 4. 输入分布

两实验共享同一采样模块。输入直接在合法编码集合抽取，不能先抽连续数再量化。所有分布默认排除零、次正规数和特殊值。格式解码仍需明确支持输入 FTZ 语义并测试。

保留七种分布：

1. positive：raw exponent 均匀；给定 exponent 的合法 fraction 条件均匀；两侧全正。
2. uniform：与 positive 相同幅度规则；两侧符号独立公平。
3. exponent_gaussian：raw exponent 按截断离散高斯权重生成；fraction 条件均匀；两侧符号独立公平。不保留额外的数值 gaussian 分布。
4. cancellation：复用 exponent_gaussian 的幅度，按精确乘积幅度从大到小贪心分配乘积符号，使其与当前和相反；精确和为零时随机选符号；随机分解成两个输入的符号，最后打乱 lane。**不拒绝幅度样本**。记录每个 block 的 rho=abs(s_b)/sum(abs(products))。支持同幅度独立随机符号的诊断对照，但不新增第八种默认分布。
5. laplace：目标连续形状为单位方差 Laplace，但只用于定义编码 PMF。
6. student_t3：t(3)/sqrt(3) 对应的单位方差形状，用于编码 PMF。
7. outlier：0.99*N(0,1)+0.01*N(0,8²)，整体除以 sqrt(0.99+0.01*64)，用于编码 PMF。

后三种分布采用区间积分而非 pdf 点值近似：对正正常编码的有序值 v_j，相邻边界取算术中点；最小/最大外边界分别向外延伸半个相邻间距，下界不小于零。质量为 F(u_j)-F(l_j)，在所保留正编码区间上重新归一化；然后独立采样公平符号。排除区间和外部尾部不压到端点编码。实现尾概率时避免 CDF 相减的消减误差，允许稳定的 survival function/解析公式或可靠库函数。

元数据记录边界规则、截断支持、目标参数、归一化质量、实际离散 RMS 和幅度分位数。此分布是合成形态，不声称代表真实 LLM 张量。

可调整默认参数：FP8 正常指数 1…15，exponent_gaussian 中心7、sigma1；TF32 采样指数96…158，中心127、sigma4。它们不构成跨格式同分布的控制实验，文档必须说明。尾数规则和编码支持必须验证。

使用独立随机流区分幅度、符号、lane 排列；随机流由稳定算法结合主 seed、格式、分布、样本编号和用途生成，不使用 Python 随机化 hash。扩充样本数或 Bmax 后，既有样本的前缀保持不变；并行调度不影响数据。

## 5. 两个独立实验

### W 实验

- W 固定完整扫描 `[18,19,...,41]`，24 点，不用粗扫或历史阈值缩小范围。
- 同一次运行固定 B，所有 W 使用完全相同样本。
- 建议默认 B=64（K=1024），作为显式配置，非不可变需求。
- 输出各指标随 W 变化。

### B 实验

- 同一次运行固定一个 W，不要求先完成 W 实验。
- B 是更新次数，不是点积项数。
- 建议默认 B=[1,2,4,8,16,32,64,128,256,512,1024]，K 最大16384。
- W 为必填参数；不得自行将历史29/37或其他数字定义为最优 W。smoke 测试可以明确选择任意合法 W。
- 同一条最大长度序列的前缀提供各 B 结果。
- 输出各指标随 B 变化。

默认两格式、七分布。正式样本建议 seeds=1…5，每 seed 2000 条，总10000条；这是可调整计划，不要求本次执行。smoke 运行只需很少样本和较小 B。

如果计算 bootstrap 区间，以序列为重采样单位，并对同一条序列的所有 W/B 使用同一重采样索引。可作为独立分析步骤，避免每次执行都消耗额外成本。不强制本轮实现 alpha 拟合；先完成原始指标曲线。

接口重点：Format、Sampler、AlignmentPolicy、RoundingPolicy、Reducer、Accumulator。只实现当前策略，避免建设通用插件注册平台。

- Format 提供合法编码、精确解码/乘法、窗口参数；不得实现实验循环。
- Sampler 返回输入编码；幅度 PMF、符号策略分开。
- Reducer 返回完整 dyadic 部分和及诊断；不得自行转 FP32。
- Accumulator 接收 FP32 状态与 dyadic 部分和，返回正确舍入的 FP32 状态及局部诊断。
- Reference 独立组织精确点积和无窗口损失路径，不能调用候选 reducer 计算真值。
- Execution 执行一条序列与快照；W/B driver 只组织扫描，不复制计算核心。
- Metrics 不依赖格式或采样实现。
- Plotting 只读取结果，不调用采样/计算引擎。

可以流式处理样本并复用共享中间量；不要保存所有 W 下每个 block 的完整轨迹。采样与执行顺序必须确定，优化不能改变累加顺序。

## 8. 必须验证的关键性质

1. 正负数和 halfway 的 RNE、FP32 正常/次正规边界、进位、精确抵消及溢出处理。
2. 构造 `acc=-1, partial=1+2^-24`：新更新结果必须为2^-24，而不是提前FP32舍入后的0。
3. 完整乘法和窗口对阶与独立精确算术 oracle 一致；窗口总宽关系正确。
4. 对每个有限样本，精确验证总误差分解恒等式。
5. 当所构造样本的窗口无丢位时，候选与路径参考一致；不得把所有随机样本W=41都精确当成要求。
6. B=1 等边界、同W不同driver的一致性、同样本前缀一致性、增加Bmax/样本数后旧前缀不变。
7. 七分布编码合法性、PMF非负及归一化、有限范围的采样频率、cancellation保持幅度且无拒绝筛选。对照使用同幅度时可通过独立sign stream验证。
8. 零分母、全零误差、精确match、p99插值、事件计数和严格JSON读写。
9. 从保存的逐样本记录重新计算指标，与首次汇总一致。
10. 两种格式和两种实验的端到端smoke；W smoke仍应覆盖全部24个W，可以减少样本和B。
11. 实际检查生成图：轴、分布面板、图例、零值、缺失值、事件标记正确，文字不截断。

精确 oracle 可使用 Fraction/独立位级算法构造少量有针对性的测试。不能只比较共享同一实现的两个入口来证明舍入正确。
