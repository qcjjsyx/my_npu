# 新架构已确认约束

确认日期：2026-11-11；2026-11-12 补充确认入口转换、乘法前端接口与归约树。累加器有限工作位数据通路于 2026-11-11 同日确认：2位真实低位＋sticky、45位共享加法器、三段算术流水与D=3、两条累加通路各3组上下文、状态范围及断言口径。

本文记录新一轮多精度 MAC 设计讨论中已确认的需求，不表示现有 RTL 已实现或验证这些需求。旧架构文档和 SystemVerilog 基线仅作为背景与功能参考；变更历史由 Git 记录。

## 应用与设计目标

- 面向 LLM 推理，优先考虑 MXFP8、MXFP4 的计算效率。
- 解除 500 MHz 的硬性频率要求，当前优先确定功能与数值行为，关注多精度资源共享及可验证的研究贡献。实际频率后续通过综合和时序分析报告，不预设达标数值；II=1 的持续供数目标保持。
- 面积约束较宽松，但不同精度之间的乘法资源共享是核心要求。不能仅以按格式配置独立乘法核心并进行输入路由来替代共享设计。

## 输入格式与乘法组合

| 输入格式 | 支持要求 | 乘法组合 |
|---|---|---|
| FP16 | 普通浮点 | FP16×FP16 |
| BF16 | 普通浮点 | BF16×BF16 |
| FP8 E4M3、E5M2 | 支持普通格式及 MX 格式 | 各自同格式相乘，以及两种 FP8 之间相乘 |
| FP4 | 支持普通格式及 MX 格式，元素为 E2M1 | 同格式相乘 |
| INT8 | 支持普通整数及 MX 格式 | 同格式相乘 |
| INT4、INT16 | 普通整数 | 各自同格式相乘 |

- 不支持 FP16×BF16 异格式相乘。
- 不要求支持浮点与整数混乘，也不要求支持整数跨位宽相乘。
- FP8 异格式组合支持 A/B 双向接口：E4M3×E5M2 和 E5M2×E4M3 均属于支持与验证范围；普通 FP8 和 MXFP8 模式均适用。
- 一侧普通模式、另一侧 MX 模式的混用不属于当前对外支持和测试范围，测试不提供此类数据；不为此增加专门的硬件拒绝逻辑。未验证的行为不作为接口保证，也不据此声称支持该能力。
- 整数使用补码编码，合法码值采用对称范围，排除最小负数编码：INT4 为 `[-7, 7]`，INT8 为 `[-127, 127]`，INT16 为 `[-32767, 32767]`。

## MX 格式依据

MX 格式参考 [OCP Microscaling Formats (MX) v1.0](<../../references/papers/OCP_Microscaling Formats (MX) v1.0 Spec_Final.pdf>)，选择 MXFP8 E4M3/E5M2、MXFP4 E2M1 和 MXINT8 子集，不要求支持 MXFP6。

- 上述 MX 格式均采用 32 元素缩放块和 8-bit E8M0 共享 scale；普通 FP8、FP4、INT8 模式不附带这一 MX 块缩放要求。
- 普通 INT8 的数值直接为补码整数 q。MXINT8 的整数码值 q 对应元素值 `q × 2^-6`；块内实际数值为 `scale × q × 2^-6`。两侧 MXINT8 相乘时需计入 `2^-12` 权重，不能将该隐含缩放套用于普通 INT8。
- MX 缩放块长度与每次输入的归约宽度 K 是不同概念。FP8 已选 K=16，FP4 已选 K=32；MXFP8 的局部贡献先分别应用 scale，再按 P1-3 的逐份贡献交错累加合同更新各自输出的状态。块对齐与每份输入携带 scale 的约束见 P1-3。
- 元素特殊值与 scale NaN 的输入约束见下文。合法输入的内部范围与边界按下文合同执行；累加状态的有限范围见 P1-3「有限工作位补码累加通路」。不能据此声称完整规范合规性已获验证。

## P0-1：计算边界与输入数值合同

本项的计算边界、输入映射及组合范围已确认。普通/MX 单侧混用的范围限制按上述约定执行；累加原则按 P1-3 已确认合同执行，状态精度按P1-3选定为p_acc=40；内部数值范围推导与边界口径见 P1-3「有限工作位补码累加通路」，位级验证仍待完成。

### 实现范围与模块职责

- 实现范围仅包括独立输入转换模块和 MAC 核心；核心止于 ACC 上下文状态寄存器及完整状态交接，最终 FP32/INT32 转换位于外部。量化算法、量化 scale 的生成及相关软件不属于本项目此次实现内容；已编码的元素及已有 MX scale 由外部提供。
- 独立输入转换模块位于 MAC 核心之外，负责原始编码分类、元素特殊值替换、subnormal 解码、内部字段构造与打包。
- MAC 入口为乘法前端，接收转换后的内部字段及必要的模式、scale 和事务信息，不再次对原始元素编码进行分类和替换。
- 浮点补码系数在 MAC 外部输入转换模块中生成；整数保留已有补码数值，不重复进行符号转换。MAC 乘法前端接收准备好的计算字段，负责必要的路由、扩展、部分积生成与重构。
- 固定容器的位宽与布局按 P1-4「入口转换与前端接口」确定为每前端每侧 22-bit 字段 bundle；广播方式及寄存器位置按P1-5设计稿执行。将补码转换放在外部模块不等于已将其与乘法组合路径隔开，也不构成时序达标结论。
- MX scale 的生成在范围之外，正确应用输入 scale 属于 MAC 核心职责。原始 E8M0 或其无损解码信息必须与所属数据正确关联。
- 旧架构在 PSUM 与 ACC 之间设置独立 MX 功能流水级，应用当前部分和的 scale，并适配 ACC 输入表示；它不负责生成量化 scale。新架构沿用该功能位置，贡献 scale 应用与无损规格化在该级执行（见下文），本轮设计稿采用独立R_MX物理级，见P1-5。
- 跨块 scale 仅作用于新贡献，内部采用补码有效数加指数状态，按 P1-3 执行；p_acc=40、signed41系数及signed10最高位指数已确认；有限工作位数据通路、范围推导与规格化方案见「有限工作位补码累加通路」，位级验证待完成。

### 元素输入映射

- 元素 NaN 映射为零；元素 ±Inf 映射为对应源元素格式的带符号最大有限值，仅适用于该格式存在相应特殊值编码的情况。
- ±0 统一为零；subnormal 在入口转换中精确保留，不执行输入 FTZ。精确保留可以通过 hidden 与有效指数构造实现，不要求乘前强制规格化。
- 上述有限化映射沿用旧实现的元素处理规则，是本设计明确选择的输入语义，不表示完整 IEEE 或 OCP 特殊值传播语义。
- MX 元素替换后仍需应用所属块的 scale；元素有限不保证缩放后数值能由后级有限范围表示。
- 整数输入仍遵循前述对称合法范围，不因入口转换而自动钳位非法最小负数编码。

### MX scale 合法输入域与后续数值边界

- 有效 MX 输入的 E8M0 scale 限定为 `0x00…0xFE`；`0xFF`（NaN）排除在当前支持域之外，不定义其硬件恢复行为。
- 上游负责提供合法 scale，正常数值测试遵循此输入域；验证环境应检查该约束，不能仅以测试未出现非法码代替合同定义。
- `0x00` 表示 `2^-127`，不是零；非 MX 模式不应用 MX scale。
- 输入映射后的有限操作数与合法 scale，不免除对内部位宽和指数范围的设计要求。累加舍入按 P1-3 执行；合法输入且从零开始的累计过程中的内部范围与边界已按 P1-3 确定，不需要内部溢出、下溢或 Inf/NaN 处理，不默认沿用入口特殊值映射。

## FP8、FP16、BF16 内部计算表示

### FP8 统一解码与指数折叠

- E4M3 固定采用 E4M3FN：有 NaN、无 Inf；原始 `exp=15、frac=7` 为 NaN，`exp=15、frac<=6` 仍为有限正常数。先按源格式分类并执行既定特殊值映射，再构造内部计算字段，不能将指数全 1 整体判为特殊值。
- E4M3FN、E5M2 的内部指数统一采用 **bias=15**。E4M3FN 的有效指数加 8，E5M2 的有效指数保持不变。
- 两者采用 3 位 fraction 基准：E4M3FN fraction 保持不变，E5M2 fraction 末尾补零。幅值由 `{hidden, frac3}` 构造，前补零后按符号条件取负，得到 signed5 补码尾数。
- 非零 subnormal 使用 `hidden=0、Eeff=1`；E4M3FN 在此有效指数基础上加 8，不能直接对原始零指数字段加 8。正常数使用 `hidden=1、Eeff=原始指数`。
- 上述解码中间表示为 unsigned5 有效指数 Eu 与 signed5 系数 m，满足 `x=m×2^(Eu-18)`；它不再作为最终 MAC 输入字段。外部转换模块进一步令 `Q=Eu>>2`、`r=Eu mod 4`、`M=m×2^r`，最终提供 **unsigned3 粗指数 Q + signed8 补码系数 M**，满足 `x=M×2^(4Q-18)`。先扩位再左移；E4M3FN、E5M2 的最大系数绝对值分别为120、112。此有限数重编码精确保值，不定义新的外部浮点格式。
- 零及映射成零的输入输出零尾数、零指数占位；零乘积不参与有效指数 MAX。内部字段不再按外部浮点格式重新分类。
- FP8 完整系数乘积 P 可用 signed16 容器；粗指数和 `T=QA+QB` 使用 unsigned4，元素乘积为 `P×2^(4T-36)`。零及映射成零的输入仍输出零系数、零指数占位。

### FP16 乘前折叠与 BF16 乘后折叠

- 保留外部转换模块提供补码系数的接口，不改成独立符号加幅值。先执行既定特殊值映射；正常数 hidden=1、有效指数 E 为原指数，非零 subnormal hidden=0、E=1。零使用零系数和零指数占位。
- FP16 先构造 signed12 系数 `m=±(hidden×1024+frac)`，满足 `x=m×2^(E-25)`；再令 `Q=E>>2`、`r=E mod 4`、`M=m×2^r`。MAC 字段为 unsigned3 Q 与 signed15 M，`|M|<=16376`，`x=M×2^(4Q-25)`。完整系数乘积 P 可用 signed30 容器，unsigned4 粗指数和 T 对应元素乘积 `P×2^(4T-50)`。
- BF16 **乘前不折叠指数**。MAC 字段为 unsigned8 有效指数 E 与 signed9 系数 `m=±(hidden×128+frac)`，`|m|<=255`，`x=m×2^(E-134)`。完整系数乘积 P 使用 signed18 容器，unsigned9 指数和 `T=EA+EB` 对应元素乘积 `P×2^(T-268)`。有限非零输入的指数和最大508，不能使用8位乘积指数。
- 上述宽度是计算字段或足够的乘积容器，不都代表数学最小位宽；公共打包和流水按P1-5设计稿。
- BF16 在精确形成 signed18 乘积后执行 postfold：`r=T mod 4`、`Q=T>>2`、`P′=P<<r`。先扩位再左移，P′采用 signed21 系数容器，Q采用 unsigned7；满足 `P×2^(T-268)=P′×2^(4Q-268)`，不改变 signed9×signed9 乘法器。零乘积统一为零系数及零指数占位。
- BF16 postfold 归入乘法功能流水级，在完整乘积重构之后、局部 MAX 和对阶之前完成；不另设独立 postfold 功能级。此功能归属不等于已经确定物理寄存器边界、组合延迟或时序达标。
- FP8、FP16、BF16 postfold 均按粗指数差执行4 bit粒度对阶，各组独立MAX并排除零乘积。重编码精确保值，但有限窗口结果不承诺与折叠前逐位一致；窗口和截断定义见 P1-3。
- 借鉴NVDLA的指数折叠，不照搬其两个carry-save向量分别移位的语义。本项目先精确重构单一完整乘积，再按下述合同截断对阶；乘法器内部门级形式不作为功能合同，重构与归约电路按P1-5设计稿。

## P0-2：吞吐、并行度与输入复用

- 输入启动间隔目标为 **II=1**，每拍接受一组新输入，不要求单组输入一拍完成；后级归约和累加必须持续承接对应吞吐。
- **以 16 个物理乘法前端为配置基准**，FP8 每拍形成 **32 个完整元素乘积**，FP4 每拍形成 **64 个完整元素乘积**，对应每前端分别形成 2 个、4 个完整乘积。16 个前端仍是当前讨论基准，不是不可调整的最终结构；上述总吞吐目标以该配置为前提。
- INT4、INT8、INT16 的已选K/G分别为32/2、16/2、8/1，对应64、32、8个完整乘积/拍。FP16已选一组dot8；BF16已选一组dot16，不使用其32个直接乘积/拍的全部硬件能力。各格式的供数与持续承接能力需分别验证。
- 用 K 表示一次输入中每个输出的乘积项数，用 G 表示独立输出组数。
- 允许 K、G 共同变化，不限制低精度只能扩大 G。用 N 表示物理前端数、P 表示每前端每拍完整乘积数；资源充分使用且每个乘积仅用于一个输出时，`N × P = K × G`。全部格式的K/G见P1-3已确认表；这些选择均以16个物理前端为前提，端到端持续承接仍需验证。
- G=2的FP8、FP4、INT8、INT4模式各自保留两个group独立的 A/B 输入；跨输出的共享 A/B 或广播由 MAC 外部供数网络负责。MAC 不强制两组共享输入或对应矩阵的同一行、同一列。具体更新语义见 P1-3。
- INT16采用两前端同时生成四部分积的映射，不采用单前端两phase分时乘法。已选K=8、G=1，接口及流水按P1-5设计稿执行，不能超过每拍8对新INT16操作数的持续乘法能力。

## P1-3：归约、累加、输出与舍入合同

### 第一步已确认：输出分组与交错更新语义

| 模式 | 每个输出贡献的乘积项数 K | 独立输出贡献数 G | 每拍完整乘积数 |
|---|---:|---:|---:|
| FP4、INT4 | 32 | 2 | 64 |
| FP8、INT8 | 16 | 2 | 32 |
| BF16 | 16 | 1 | 16 |
| FP16、INT16 | 8 | 1 | 8 |

- 上表均以16个物理前端为配置基准，MXFP4、MXFP8、MXINT8沿用对应普通格式的K/G。具体乘法映射见P1-4；这些是已选吞吐目标与资源映射，不是已验证的端到端吞吐。
- 每个 group 允许并采用多个独立输出上下文交错供数，以满足浮点累加流水的反馈间隔。II=1 指合法交错调度下持续每拍接受新输入，不再要求同一输出连续每拍更新，也不再禁止依赖其他独立输出填充流水。只有单个或不足数量的活动输出时，允许因反馈依赖降低吞吐；不承诺这种情况下仍达到 II=1。外部负责按约定组织输出访问，同一输出的贡献顺序保持不变。
- 接受输入、形成局部部分和、更新累加状态是三个不同事件，允许通过流水分离；II=1 不表示输入当拍完成更新。有限缓冲不能替代持续累加能力，不因入口每拍接收就认定整条 MAC 达标。
- 用 L_total 表示每个输出完整点积长度，与 K、上下文数量和流水延迟区分。以 L_total=128 为例，FP8 每个输出需要 8 次 dot16 贡献，FP4 每个输出需要 4 次 dot32 贡献；这些贡献可与其他输出交错，不再保证在连续 8 拍或 4 拍中完成该输出的供数。以上不含流水填充、结果提交或换组开销，也不将 128 冻结为唯一或最大支持长度。
- G=2模式的两个 group 接收独立的 A0/B0、A1/B1，输出的矩阵坐标由外部映射，MAC 不要求两输出同行或同列。若复用 A 或 B，由外部将相同数据送至相应输入，MAC 不需要检测输入相等或采用强制共享接口。两组 MX scale 分别与所属数据关联，不能因输入值相同而默认尺度相同。
- 组间输入独立不禁止完成同一元素乘积所需的内部数据分发，例如 FP16 跨前端部分积重构中的操作数分段扇出；这与跨输出共享 A/B 不同。
- 同一 group 内维护多个未完成输出的独立累加状态是本次选定方向；group 表示每拍并行计算的分组，不再等同于唯一活动输出。上下文数已定为每条累加通路3组（共6组，见下文），状态编号、配对映射与调度按下文接口执行。G=2 每拍产生两组独立贡献，后级必须提供相匹配的两路更新吞吐和状态访问带宽，不能以一条每拍只处理一份贡献的通路直接承接两组。
- FP4/INT4 的四个乘积保持独立；两个同组乘积不在前端内先相加，而是在归约级通过 offset-binary packing 和最终加法合并（见 P1-4「入口转换与前端接口」）。局部加法位置已按该结构确定；寄存器边界与旁路采用P1-5设计稿。

### 第二步已确认部分：局部归约合同

- FP4 正式采用 MAC 外精确整数化 `q=2x`，`q∈{0,±1,±2,±3,±4,±6,±8,±12}`，使用 signed5 补码系数。每组 dot32 先计算精确整数和 `S=Σ(qA×qB)`，在应用 MX scale、合入长点积累加状态之前不做中间舍入。
- FP4 单个系数乘积最大绝对值为 144，最小需要 signed9；32 项整数和最大绝对值为 4608，最小需要 signed14。各级必须正确扩位并精确保留求和结果，具体内部位宽分配与加法位置不在此冻结。普通 FP4 局部贡献为 `S×2^-2`。
- MXFP4 的同一局部整数归约必须具有一致的组合尺度，此时贡献为 `S×2^(sA+sB-2)`，sA、sB 为 scale 的实际二进制指数。无需逐元素 MAX、对阶或舍入；块对齐与 scale 关联按第三步约束执行，不同贡献按既定顺序更新累加状态，不将此结论推广为长点积累加也无需对阶。
- **FP8、BF16、FP16 均采用：精确形成完整乘积 → BF16执行乘后折叠 → 各group独立选择非零乘积最大粗指数 → 对齐到有限窗口并逐项算术截断 → 精确整数求和。** 此决定替代此前局部逐项RNE要求；截断明确为向负无穷取整，负数大幅右移可能为-1，不按向零截断或统一清零处理。局部不保留用于逐项RNE的GRS或加一逻辑。
- 选定窗口如下；F表示在对阶系数低位精确拼接的零位数，并相应调整最低位权重，不是GRS工作位。

| 格式 | 完整乘积容器 | 对阶系数容器 C | F | 对阶保留位宽 C+F | 每组项数 | 精确归约结果位宽 |
|---|---:|---:|---:|---:|---:|---:|
| FP8（普通及MX） | signed16 | signed16 | 16 | 32 | 16 | 36 |
| BF16 postfold | signed18 | signed21 | 11 | 32 | 16 | 36 |
| FP16 | signed30 | signed30 | 8 | 38 | 8 | 41 |

- 统一数值定义：各项为 `A_i×2^(4Q_i-b)`；FP8、FP16的A为完整乘积，Q为两操作数粗指数之和，b分别为36、50；BF16的A为P′、Q为乘后粗指数，b=268。令 `Q*=max(Q_i | A_i≠0)`、`d_i=4(Q*−Q_i)`，则 `n_i=floor(A_i×2^(F−d_i))`、`N=Σn_i`，局部贡献为 `N×2^L`，`L=4Q*−b−F`。先扩位再移位；全零组直接输出零。
- B=C+F位对阶结果的bit0权重为 `2^L`，最高非符号位权重为 `2^(L+B−2)`，符号位权重为 `−2^(L+B−1)`。32位窄数据在共享对阶/对齐通路中只在高位符号扩展，不改变L。归约增长位为dot16的4位、dot8的3位，树内不再截断、舍入或回绕。
- MX scale仍在局部归约后通过指数加上 `sA+sB` 精确应用。局部截断的整数精确和不等于原始浮点乘积的精确和；后续状态RNE及最终转换规则不因局部截断而取消；不再设置配对RNE。
- 保持FP8两组dot16、每拍32项对阶能力，各组独立MAX；BF16一组dot16、FP16一组dot8。局部归约树已选定为 **2棵16输入、32-bit输入、36-bit输出的加法树加1个41-bit最终加法器**：FP16的38-bit对阶系数按19/19拆分复用两棵树，FP4/INT4按offset-binary packing复用两棵树，FP8/INT8每个group一棵树，BF16/INT16一棵树。平衡树、MAX/对阶器分配、路由和物理流水按P1-5设计稿补齐。II=1及L_max=16384目标不变，不采用1024长度限制。
- 数值依据为[local_alignment原运行](../../results/numerical/local_alignment/runs/runs0/20261109T094102_703475Z_7dd9f459/)及[BF16乘后折叠同源对比](../../results/numerical/local_alignment/analysis/bf16_postfold32/)。从FP32量化生成目标输入，参考从量化编码及MX scale出发，后续精确累加以隔离局部损失；并非完整累加器、RTL或PPA证据。Gaussian/Laplace/Student-t3/outlier四分布、L=16384、各模式768样例中，BF16 postfold bit-match=82.29%、ULP P99=4、最大2596；FP16 F=8截断bit-match=95.70%、ULP P99=1、最大7。输入分布、近零结果及饱和样例必须分开解释，未据此定义统一验收阈值。

### 第二步已确认部分：长点积累加原则

- 浮点及 MX 路径采用统一的自定义“有限精度有效数 + 指数”累加状态，有效数继续使用补码；普通 FP4 也走该浮点累加路径。内部状态不预设为标准 FP32，最终输出格式独立确定；不直接采用其他架构的 FP44/FP48 名称来冻结位宽。
- **采用多上下文交错、逐份局部贡献直接累加，取消相邻贡献配对级。** 对输出上下文 o，令 v[o,t] 为该输出第 t 份已完成局部归约、格式权重和 MX scale 应用的贡献，则从零开始时 C[o,0]=0，更新严格为 `C[o,t+1]=RNE_acc(C[o,t]+v[o,t])`。每次先将旧状态与完整新贡献相加，再执行一次状态 RNE；不得先将任一操作数独立舍入到目标状态精度。暂停供数后从原槽状态继续同一序列。
- 此决定替代原 `b_j=RNE_pair(v_2j+v_(2j+1))`、`C_next=RNE_acc(C_old+b_j)` 的配对合同。取消配对算术级、配对 RNE、配对缓存、奇偶控制及奇数尾份专用旁路；每份贡献都通过相同的状态更新路径。状态 RNE 次数和运算结合顺序与原方案不同，不承诺逐位一致，也不预判误差必然增大或减小；精度与状态位宽按新合同评价，当前选择及证据见下文。
- 交错的是不同输出的独立状态，不是将同一输出拆成奇偶子链或多个部分和后合并。同一输出内部仍按贡献顺序更新，不允许以任意重排或预合并替代上述公式。
- 借鉴 NVDLA 的多状态存储及交错访问组织：读取所选输出旧状态，经对阶、加法、规格化和 RNE 后，按随流水传递的状态标识写回。仅借鉴组织方式，不继承其有效数位宽、指数范围、舍入或边界语义。每条服务通路目标为每拍可启动一次独立更新，允许状态反馈跨多拍，不再假设反馈必须两拍完成。
- 同一状态的再次访问必须等待前次结果可供读取。令 D 为完整实现允许的最小同状态发起间隔，须计入状态读取、算术流水、写回可见性及同拍读写规则；若采用均匀轮转，满吞吐所需独立上下文数至少为 D。D 不等同于最终 FP32 输出延迟，不直接从 NVDLA 的流水注释或 bank 数推定。当前选定三段算术流水、D=3；G=2 的两条独立累加通路各维护3组上下文，共6组，同一输出的贡献固定由同一条通路处理。外部负责合法调度，指定编号读取接口及D=3周期关系见下文。
- 上下文存储以少量寄存器组抽象，SRAM宏、容量及bank组织不纳入本项目研究；上下文数量和重访时序依算术实现确定，不要求复制NVDLA的SRAM规模。取消配对级预计减少一套浮点算术处理，但新增多状态存储及选择控制；没有综合证据，不声称累加器或完整 MAC 面积减半。
- 最后一份贡献只需携带所属输出的结束标记，执行正常状态更新；该次更新完成后才能提交。贡献份数的奇偶性不再影响算术路径。G=2 的对应事务仍遵循第四步共同结束约束，上下文使用共同2-bit ctx及first/last关联。
- 普通 INT4/INT8/INT16 在支持的输入、零初值及点积长度范围内精确累加，不采用逐次饱和或截断；最终 INT32 输出饱和按第四步已确认规则执行。
- 所有新事务从零开始，不提供外部初值装载或中途状态保存恢复接口。完整状态读取仅面向last最终写回后的已完成上下文，外部接收后释放。
- 允许停止供数并保持原上下文；在途更新继续完成，之后以同一ctx、first=0继续累计。暂停期间不得复位或覆盖状态，未完成事务始终占用原槽，不支持换出后恢复。
- p_acc=40、signed41系数及signed10最高位指数按下文确认；工作位、尾部处理及规格化数据通路已选定（见下文），统一精度验收阈值与位级等价性验证仍待完成，不从精度选择推断时序已达标。

### 第二步已确认：40位主精度、直接补码加法及尾部处理原则

#### 状态表示和位宽口径

浮点及全部 MX 路径选择 `p_acc=40`。p_acc 是对阶主窗口的幅值精度，包含最高有效位、不包含符号位，同时是规格化结果写回时保留的幅值精度。主窗口以外允许保留本次运算必需的真实低位、进位和尾部摘要，不将这些工作位称为额外状态精度，也不能将物理加法器总宽度直接称为40位。

非零状态定义为：

```text
C = M × 2^(H-39)
2^39 <= abs(M) < 2^40
H = floor(log2(abs(C)))
```

M 使用 signed41 补码容器；H 使用 signed10，直接存储幅值最高有效位的实际指数，无 bias，编码范围为 [-512,511]。最高位指幅值的最高有效位，不是补码符号位。零统一为 M=0、H=0，无内部负零；非零状态不使用 signed41 的最小负数编码 -2^40。浮点数值字段共51位，不含模式、上下文关联及其他必要控制信息。完成读取保留这些数值字段，不进行重新舍入。

signed10 是指数存储宽度，不是所有指数中间运算的宽度。指数差、规格化移位及舍入进位修正必须使用足够的中间位；覆盖完整 signed10 编码域的指数差与 H_next 中间量使用 signed11。合法输入、MX scale 与16384项下的范围推导见「有限工作位补码累加通路」，位级验证仍待完成；不得静默回绕，也不将最终FP32饱和、渐进下溢自动套用到内部状态。

#### 局部贡献入口和无损规格化

新贡献保留 `v=N×2^e` 的完整信息。浮点局部最低位指数及 MX 缩放按已确认局部公式执行；下表中的 `e_loc` 不含 MX scale，MX 级最终指数为 `e=e_loc+h`：

| 路径 | N的容器 | e_loc（不含 h） |
|---|---|---|
| FP8／MXFP8 | signed36 | 4Q*−52 |
| BF16 postfold | signed36 | 4Q*−279 |
| FP16 | signed41 | 4Q*−58 |
| FP4／MXFP4 | signed14 | −2 |
| MXINT8 | signed19 | −12 |

`h=sA+sB`，普通模式 h=0；只能在 MX 级加一次 h，不得在局部表预加。零贡献规范为 `N=e_loc=h=0`。非零贡献令 k=floor(log2(abs(N)))，则 H_v=e_loc+h+k、M_v=N×2^(39-k)。合法局部系数的幅值上界为 |N|<2^40：五条路径中最大的是 FP16 的 549,219,074,048<2^39（余量约0.098%），故 k≤38、该步骤只做无损左移，不丢位；不能在入口独立舍入。FP16 signed41是容器，须结合合法系数范围理解，不能把任意容器位模式当成合法贡献。MX scale只调整新贡献指数，不改变旧状态的实际数值。

新贡献的零检测、无损规格化和scale指数加法放在状态反馈环外的 MX 功能级执行。旧状态与新贡献在统一位权下进行补码加法，写回仍严格满足 `C_next=RNE_40(C_old+v)`。

#### 直接补码数据通路

采用直接补码对阶、加法和RNE的方向，不将“转为符号＋幅值再相加减”作为必需步骤。处理顺序为：

```text
补码旧状态 + 完整新贡献
  → 指数比较、符号扩展、算术对阶与尾部生成
  → 共用补码主加法器
  → 结果零检测、规格化、尾部整理
  → RNE加一及规格化边界修正
  → 补码状态写回
```

局部多项归约选择补码，是因为统一位权下可以直接使用有符号加法树／CSA；原码符号位不能直接当普通数值位送入整数加法树。此选择不妨碍在前导位检测等局部逻辑中使用符号相关操作，但不要求整条数据通路进行幅值转换。NVDLA的carry-save及符号补偿组织仅作为背景，不直接继承其对阶截断或舍入语义。

#### 补码右移和RNE的准确含义

补码算术右移是向负无穷取整，而不是向零截断。对整数M右移d位，可精确写成：

```text
M / 2^d = q + r
q = floor(M / 2^d)，0 <= r < 1
```

例如 -11/4=-2.75=-3+0.25；窗口内整数为-3，尾部是加在它上的非负余量0.25。不能按负幅值解释这个尾部，也不能仅因数为负就将RNE改为减一。

规格化后，以最终保留最低位的权重u为单位，将精确结果写为 `x=(q+r)u`。RNE在 r<1/2 时保留q，r>1/2 时取q+1，恰好一半时选择q与q+1中的偶数。因此正负数均可用：

```text
inc = G & (R | S | LSB)
rounded = q + inc
```

前提是G/R/S正确描述该向下取整整数q下方的余量：G为半ULP位，R为下一位，S为再下方非零位的OR；LSB为q的最低位。补码最低位可直接判断奇偶。例：+2.5→+2、+3.5→+4、-2.5=-3+0.5→-2、-3.5=-4+0.5→-4。此RNE是相加结果的舍入，不能提前对两个操作数分别执行。

补码结果可用前导符号位检测辅助规格化，但H仍须满足幅值最高位定义。负的精确二次幂等边界必须修正，不能仅以“最高两位不同”替代本状态的全部规格化规则。舍入进位后应重新检查规格化及指数；完全抵消输出规范零。

#### 为什么必须区分真实低位和sticky

真实低位有明确位权，可以参与加法、进位和规格化移位；sticky只表示更低区域是否非零，不代表一个确定大小的数。以下以p=5说明，实际设计p=40遵循相同原则。

**例1：sticky不能单独决定舍入。** 在1附近，5位幅值主窗口为 `1.0000`，最低位u=1/16。`1+1/64`和`1+3/64`分别为 `1.0000|01`、`1.0000|11`；竖线右侧为窗口外真实位。前者RNE为1，后者为1+1/16。若将右侧所有位直接OR，两者都变为“主窗口1.0000、sticky=1”，将无法区分舍入方向。因此必须保留必要的真实保护位，只压缩更低尾部。

**例2：抵消后低位可能成为唯一结果。** `1-31/32=1/32`，两个操作数都能用5位幅值精确表示。对齐到指数0为 `1.0000|0 - 0.1111|1 = 0.0000|1`。按u=1/16计，旧状态是16，新贡献是-15.5=-16+0.5，正确和为0.5u。若只相加主窗口16与-16，将错误得到零。必须先保留这个真实低位完成相加，再左移规格化得到 `1.0000×2^-5`。这里的二进制示意写的是数值，不是原码硬件接口。

**例3：一般情况下尾部还可能向上进位。** 若两个操作数分别为 `(A+r_a)u`、`(B+r_b)u`，当r_a=r_b=0.75时，和为 `(A+B+1+0.5)u`；而r_a=r_b=0.25时没有进入主窗口的进位。两种情况各自的sticky均为1，所以不能只对两个sticky做OR或普通加法来恢复尾部和。这是一般示例，不要求本电路设计一个任意双尾部运算器。

实现上先对两个至多40位幅值的操作数无损规格化，并精确放置大指数操作数，只右移另一侧，可以使窗口外尾部主要来自被移位的一侧。指数接近、可能深度抵消时必须保留足够真实位；指数差较大时可利用抵消深度有限的性质压缩远端尾部。任何方案均须逐位等价于精确相加后RNE，不能把sticky在左移时当作真实有效位。

选中方案为 **2位真实低位＋1位sticky、45位共享加法器** 的补码数据通路，位权、生成方法与正确性依据见下文「有限工作位补码累加通路」。该方案由推导确定，位级模型已验证，RTL、综合与时序未验证；在 RTL 共仿前，不得表述为已实现。不能用精度实验替代工作位正确性证明。

#### 有限工作位补码累加通路（已选定，位级模型已验证，RTL 待验证）

本节记录 2026-11-11 选定的位级实现方案。它是设计决定，不是位级等价性、时序或面积结论；验证状态见本节末。

- 工作位：**2 位真实低位（G、R）加 1 位 sticky（S）**；主加法器 **45 位**，浮点与普通整数复用，每条累加通路一套。
- 算术流水 **三段**（对阶、加法、规格化/RNE），同状态最小发起间隔 **D=3**。
- **两条独立累加通路**对应 G=2 的两份贡献/拍；每条通路维护 **3 组上下文**，共 6 组；同一输出的贡献固定由同一条通路处理，外部映射固定通路。

**位权与恒等式。** 设 `H_a=max(H_c,H_v)`、`H_b=min`、`d=H_a−H_b`，工作单位 `u0=2^(H_a−41)`，`A=4M_a`，`B=floor(4M_b×2^(−d))`，余量 `τ=4M_b×2^(−d)−B∈[0,1)`，则

```text
C_old + v = (T + τ)×u0,   T = A + B,   |T| <= 2^43 - 8
```

**步骤。**

1. 贡献无损规格化（环外，MX 级）：`k=floor(log2|N|)`，`M_v=N×2^(39−k)`，`H_v=e_loc+h+k`。要求 `|N|<2^40`，五条路径最大为 FP16 的 549,219,074,048<2^39，故只左移不丢位；零贡献 `N=e_loc=h=0` 单独旁路。
2. 指数比较：`d` 用 signed11；取大指数侧为 a、小指数侧为 b。
3. 对阶：`d≤2` 时 B 为精确左移（τ=0）；`d≥3` 时右移并产生 τ，按43位饱和并符号填充。
4. 规格化：`t` 取 T 中**与符号位不同的最高位**（正数为最高 1，负数为补码最高 0），`σ=41−t∈[−1,41]`；`T′=T×2^σ`（σ≥0）或 `T>>1`，右移丢出位并入 S。对负的精确二次幂 `T=−2^k`，该规则得到 t=k−1（比幅值 MSB 低一位）、σ 大一位、`M_pre=−2^40`，由第 6 步负端重规格化补偿；不得按 `floor(log2|T|)` 实现。
5. 舍入：`M_pre=T′>>2`；`G=T′[1]`、`R=T′[0]`、`S=τ｜丢出位`；`inc=G&(R|S|M_pre[0])`；`M_r=M_pre+inc`。
6. 重规格化：`|M_r|=2^40` 时 `M=±2^39`、`c=1`；正进位与负的 `−2^40` 都必须判。
7. 指数：`H_next=H_a−σ+c`，用 signed11 中间量，signed10 写回。
8. 零：`T=0` 等价于精确零且此时 τ=0，输出 `M=H=0`；`C_old=0` 或 `v=0` 必须旁路，不得把 H=0 当作数值指数参与对阶。

**为什么 2 位真实低位足够。** `τ>0` 只可能出现在 `d≥3`（E=2）。对 d≥3 统一有 `|T| ≥ 2^41 − 2^(42−d) ≥ 1.5·2^40 > 2^40`，故 t≥40、**σ≤1**；例如 `M_a=2^39,H_a=0`、`M_b=−(2^40−1),H_b=−3` 给出 d=3、`T=3·2^39`、τ=1/2、σ=1。`T′=T×2^σ` 的低 σ 位为 0，余量 `τ×2^σ<2^σ` 只填入低 σ 位，因此 σ=1 时只有 R 被替换，G 在 bit1 仍精确。R 单独影响判定仅当 G=1 且 S=0；而 S=0 意味着 τ=0，替换不存在，R 即真值；τ>0 时 S=1，G=1 直接进位。故 2 位足够。1 位不够：σ=1 时 G 恰落在被替换的 bit0 上，会把 `r∈[0.5,1)` 判成 `r<0.5`。

**宽度与范围。**

| 项 | 结论 | 依据 |
|---|---|---|
| 浮点 T | 44 位 | `abs(T)<=2^43−8` |
| 共享加法器 | 45 位 | 浮点最高位为冗余符号扩展；INT 合法域 `abs(C+p)<2^44` |
| 指数差、H_next | signed11 | `abs(d)<=1023`；`H_next∈[H_a−41,H_a+2]` |
| H 存储 | signed10 | 可达 `H∈[−346,306]` |

- 可达下界：`H_next>=H_a−40`。σ=41 只可能由 `T=−2` 产生（合法操作数下 `T=±1` 不可达；`T=−2` 时 `M_pre=−2^40` 必触发重规格化，c=1），其余情形 σ≤40；又 `H_a>=−306`，故 `H>=−346`。
- 可达上界：单次更新有 `|C_t| ≤ |C_(t−1)+v_t| + 2^(H_t−40) ≤ |C_(t−1)+v_t| + |C_t|·2^(−40)`，故 `|C_t| ≤ (1+2^(−39))(|C_(t−1)|+|v_t|)`。累计取保守计数 `n≤2^14`（实际 `n=L/K≤2048`），`|C_n| ≤ (1+2^(−39))^n·Σ|v_i| ≤ (1+2^(−24))·2^306 < 2^307`（`|v|<2^292`，FP8 最紧），故 **H≤306**。
- 合法输入、合法 MX scale 与 L≤16384 下，上述加法器、指数差与指数中间量均不溢出；数据通路不需要内部饱和、FTZ、Inf/NaN 或回绕。

**状态范围与断言。**

- 当前硬件仅允许从零开始并沿合法贡献序列更新。非零状态满足M归一化（`2^39<=|M|<2^40`、`M≠−2^40`）及`H∈[−346,306]`；零为M=H=0。硬件不做范围比较、不钳位、不回绕。既有模型的合法恢复域分析保留为模型适用范围，不构成硬件导入能力。
- 仿真断言（不进入 RTL）：`|N|<2^40`；`e=e_loc+h` 与 H_v 在 signed10；`T=0⇒τ=0`；浮点 `|T|<=2^43−8`；`σ∈[−1,41]`；`|M_r|<=2^40`；写回格式与 `M≠−2^40`；`d<=1023`；INT `|C+p|<2^44`；H 在已定状态范围。
- 完成读取无损交付51位浮点数值字段（M41+H10）；不提供状态恢复写入口。

**流水与上下文。**

- 三段：对阶、加法、规格化/RNE；写回在第三段末，D=3。
- G=2 的两条通路各含 45 位加法器、对阶移位、规格化舍入与状态组；均匀轮转时同状态间隔 3 拍。状态组按通路独立，不共享。
- 当前固定通路与配对ctx映射，不采用2R2W共享状态组。若后续拆分第三段，必须重新审定D与上下文数量。

**MX 级归一化。**

- 贡献归一化放在 MX 功能级（PSUM 之后、ACC 之前），在 `e_loc+h` 之后执行；输入为 N（符号扩展到 41 位）、`e_loc`、`h=sA+sB`，输出 `M_v`、`H_v`、valid。该字段划分作为与乘法前端专题的接口约定；旧 Q2.34/bias127 转换不继承。
- 该步骤是无损左移，不构成入口舍入；唯一舍入仍是加后 RNE。

**证据边界。** 位级模型与检查已实现：`hardware/verification/reference/new_arch/` 为结构固定的黄金模型与独立精确 oracle，`hardware/verification/tests/test_acc_fixed_model.py` 覆盖小 p（5/6/8）全操作数对穷举、p=40 情形空间与定向边界（含 d=3、σ=1 反例与 T=−2、σ=41 负二次幂）、变形性质、现有 accumulation_precision 代表轨迹逐步对比（6 模式、128/16384 长度）及范围端点；本地 20 项全部通过。RTL、共仿、综合与时序尚未开始；轨迹项依赖已有运行目录，数据缺失时跳过。模型级通过不等于 RTL 等价性、完整输入链或综合时序结论。

#### 普通整数复用和上下文范围

普通INT4/8/16复用主加法器，但不使用浮点p_acc限制其精度，也不转换为浮点状态。普通整数旁路对阶、规格化和RNE，符号扩展后精确相加；可保留相同流水寄存器以简化状态编号、模式及结束标记的传递。MXINT8仍走浮点路径。

对称合法输入域、从零开始、暂停续算计入同一累计过程时，`abs(C)<=16384×(2^(w-1)-1)^2`。INT4/8/16分别需signed21/29/45状态，统一整数状态采用signed45即可。合法状态下 `abs(C+p)<2^44`，45位求和足够；46位扩展只在允许任意signed45位模式作为初值时需要，而当前接口不允许外部初值装载。共享加法器取45位，浮点T的最高位为冗余符号扩展；共享物理加法器不等于两种模式必须有相同状态格式或精度。

上下文存储不作为本项目的SRAM设计课题。用少量寄存器组表示独立输出状态，保留正确的状态选择、初始化和写回关联即可；SRAM宏、容量和bank组织不在本轮实现研究范围。外部SRAM若提供状态，可经操作数寄存器进入同一算术通路；其读延迟不能因此视为零，但不在这里冻结。

算术流水选定为三段：对阶、加法、规格化/RNE；写回在第三段末，同状态最小发起间隔 D=3。G=2 采用两条独立累加通路，每拍各承接一份贡献；每条通路维护3组上下文，共6组，均匀轮转时同状态间隔为D。同一输出的贡献固定由同一条通路处理。段数与D是当前设计选择，不是已验证的周期要求；若后续拆分第三段，D与每条通路的上下文数须同步修改。上下文编号、首次/结束标记、有效信息及必要模式关联随贡献传递，不增加任意时刻快照。

### 已确认的长点积设计目标与精度参考口径

- L_total 为单个输出实际累计的乘积项数；选定 L_max=16384 作为位宽推导、内部范围分析与精度验证的设计目标，尚不是已验证的数值保证。采用 MAC 内完成完整点积的组织，不再将 16 个独立 1024 项结果交由外部合并作为当前实现候选。
- 点积可暂停供数并在原槽续算，暂停前后仍属同一累计过程，累计长度合计受L_max约束。实际长度和供数由外部组织，MAC不增加长度计数器或剩余额度管理。
- 数学参考从入口映射后的编码输入出发，包含 MX scale，精确计算乘积总和 S；外部量化误差不混入 MAC 算术误差。浮点/MX 参考输出对 S 应用已确认的 FP32 RNE、有限值饱和、渐进下溢和零符号规则；普通整数精确求和后应用 INT32 输出规则。
- 功能验证要求 RTL 与新数值合同的独立参考模型逐位一致；精度评价比较该合同与精确数学结果及参考输出的差异。沿用现有 bit-match、ULP、绝对误差、归一化误差等方法，不能将存在指标误称为已有通过阈值。
- 分别记录局部归约、长点积状态累加及最终转换误差：从精确乘积总和，依次比较局部贡献的精确总和、逐份状态更新后的最终状态精确解码值及最终输出值。当前设计没有配对舍入误差阶段；历史配对方案如作比较须明确其不同合同。局部窗口按上述选择执行；状态精度已选p_acc=40；具体通过阈值及全部格式完整数值链验证尚未完成，不继承旧模型的位宽结论。

### 第三步已确认部分：MX scale 作用于新贡献

- MX scale 通过调整新贡献的指数应用。若未缩放局部贡献为 `M×2^e_loc`，两侧合法 E8M0 scale 的实际指数为 `sA、sB`，则缩放后贡献为 `M×2^(e_loc+sA+sB)`。指数中间范围足够时，这一操作精确保值，不改变有效数，不增加独立舍入点。
- MXFP8 在局部浮点贡献的指数上加 `sA+sB`；MXFP4 的整数和 S 对应 `S×2^(sA+sB-2)`；MXINT8 对应 `S×2^(sA+sB-12)`，不得遗漏各格式的隐含权重。
- 已有累加状态保存此前贡献的实际累积数值，不随新块 scale 改变而重新缩放。缩放后的每份新贡献直接与所属输出的旧状态相加并执行一次状态 RNE；相加所需的对阶不等于对旧状态施加新块 scale。
- 指数中间值不得因窄字段而静默回绕；按已定范围在signed11中间域运算并存signed10，合法内部状态不做FTZ或饱和。本轮采用独立R_MX物理级。
- 每份局部贡献先通过 MX 功能处理应用自己的 scale，再进入长点积状态累加级；沿用旧 IP_Design.md 的功能先后关系，不继承其 Q2.34、8-bit 指数、FTZ/Inf 或固定物理级数。
- MXFP8 同块两份 dot16 分别完成局部归约及 scale 应用，再按该输出的贡献顺序各自执行一次状态更新；不合并为共同 MAX 的 dot32，也不设置配对 RNE。MXFP4 每份 dot32 应用所属块的 scale 后直接累加，不把不同块的整数和先合并再套用单一 scale。MXINT8 已选 K=16、G=2；每份 dot16 先精确形成整数和，再应用自己的 scale 及 2^-12 权重，直接进入浮点状态累加。

### 第三步已确认部分：块对齐、scale 关联与尾段供数

- 外部供数保证 A/B 沿归约维度的 MX 块边界对齐，每份局部输入不跨越任一侧的块边界。MXFP8、MXINT8 的完整 32 元素块分别分为前后两份 dot16；MXFP4 的一份 dot32 对应 A/B 各一个完整块。两个 group 独立满足约束，不要求组间块编号或 scale 相同；有效贡献顺序不等于必须占用相邻物理时钟拍。
- 每份局部输入携带所属的一对 A/B scale；MXFP8、MXINT8 同块两份 dot16 重复携带相同的一对 scale，MXFP4 每份 dot32 携带对应块的一对 scale。scale 或其无损解码信息须随所属数据或贡献正确传递，后续输入的 scale 不得覆盖尚未处理完的旧贡献所需信息。入口采用每组原始E8M0，R_IN解码为h并随固定流水传递，具体接口见P1-5。
- 尾段由外部算子及供数链路补零，MAC 每次有效输入始终接收完整 K 项，将所有位置作为真实输入处理，不区分有效元素与补零元素，不承担内部补零职责，也不为尾段增加逐元素有效掩码。外部仍须保证不跨块及 scale 关联正确；补零不改变实际点积长度 L_total，也不扩大支持长度范围。
- 数据补齐不等于结果提交，不能根据零输入判断点积结束。结束标记与逻辑提交边界按第四步执行；MXFP8、MXINT8 尾段仅需在最后一份必要的 dot16 内补零并标记结束，无需额外补发全零 dot16 来凑满 32 元素块；完成读取按上述指定编号接口执行。MXINT8按上述两份dot16组织供数；两份各自应用scale后再按该输出的贡献顺序分别更新状态，不将块长32自动解释为一次dot32归约。

### 第四步已确认部分：完整状态交接与外部输出转换约定

MAC 核心止于 ACC 上下文状态寄存器，输出完整内部状态；最终 FP32/INT32 转换及后续结果存储、消费位于核心之外，不属于本轮硬件实现范围。以下转换规则保留为外部转换与数值实验的约定，不要求 MAC 实现转换电路。

- 外部在最后一份局部贡献上标记结束，结束标记须与所属贡献同步传递。MAC 完成该贡献的累加更新后，才以最终状态形成待提交结果；接收到结束标记不表示当拍完成输出，也不能提交尚未包含最后一份贡献的旧状态。不能根据零输入或 MX 块边界自动判定点积结束。
- G=2模式的两个 group 同时结束，外部保证同一计算事务内两组贡献次数一致；两组 A/B、scale 和累加状态仍独立，只共享事务结束边界，不限制输出必须同行或同列。两份完整状态共同完成并交接，采用下文的原槽保持与外部接收后释放规则；具体端口见IP_DESIGN第1、8章，接收释放后的下一拍允许复用。
- 普通 INT4/INT8/INT16 路径最终输出 INT32。支持范围内仍精确累加，最终结果超出 INT32 范围时饱和到对应端点 `-2^31` 或 `2^31-1`；范围内精确输出，不涉及小数舍入。不因输入整数采用对称合法范围而排除 INT32 输出的最小负数。
- 浮点及全部 MX 路径最终统一输出 FP32；MXINT8 使用浮点累加状态并输出 FP32，不按普通 INT8 处理。内部累加状态仍是自定义格式，不因输出 FP32 而改为 FP32 状态。
- 最终 FP32 转换采用 RNE，从完成最后一次状态 RNE 的最终内部状态直接转换，不先经过其他较窄格式。数值顺序为 `C_final=RNE_acc(C_old+z_last)`，其中 z_last 是该输出最后一份已应用格式权重与 MX scale 的局部贡献，再执行最终 FP32 转换；不绕过最后一次状态 RNE，也不承诺等价于原始点积只舍入一次。
- 最终 FP32 转换正向溢出时饱和为最大正有限值，负向溢出时饱和为最负有限值，不以 Inf 作为有限结果的溢出输出。支持渐进下溢，保留 FP32 subnormal 并按 RNE 转换；仅当舍入结果为零时归零，不将小于最小正常数的值一律清零。
- 内部最终状态恰好为零（包括完全相消）时输出 +0；非零最终状态在 FP32 转换中舍入为零时保留原值符号，分别输出 +0 或 -0。不为精确零引入内部负零状态。
- 上述饱和和下溢规则仅作用于最终输出转换，不自动推广到内部逐次累加。入口 subnormal 精确保留、内部有限精度处理和输出渐进下溢是不同合同。合法输入、从零开始且 L≤16384 下，内部状态与指数均不越出已定范围，不需要内部 FTZ、饱和、Inf/NaN 或回绕处理；非法贡献属于输入违约，只在仿真中断言。入口 NaN/Inf 映射不自动适用于内部或输出。
- 需求背景保留为希望未来能够输出所支持的输入格式；本阶段主动简化为上述 INT32/FP32 输出，不实现多格式输出转换。未来 MX 输出的块组织与 scale 来源需要另行确定，不据此扩大当前 scale 生成的实现范围。

### 固定流水、ACC 边界与状态交接（2026-11-12 已确认）

- MAC 核心以 ACC 上下文状态寄存器为计算终点。浮点及全部 MX 输出完整 M41+H10 数值字段，普通整数输出 signed45 完整状态，另携带必要关联信息；不在核心内转换为 FP32/INT32，不设置最终结果 FIFO、容量计数或 last 空间预留。
- 内部采用固定推进的 valid 流水，数据与模式、上下文关联、first/last 同步前移，无输入时注入气泡。外部暂不接收完成状态，不冻结其他合法上下文的在途计算。正常计算采用下文valid-only准入及D=3读写关系；前向物理切分按P1-5设计稿。
- G=2 时 g0、g1 分别进入 ACC0、ACC1，独立更新各自状态，不跨组相加；G=1 时仅 ACC0 接收 g0，ACC1 无有效更新、无状态写入，不因此清空已有状态。模式切换遵循下文全部槽释放且流水排空的规则。
- last 完成最后一次累加更新并写回后，才标记对应状态完成。最终状态保留在原上下文寄存器槽内，直到外部确认接收完整状态后释放；等待期间不得复用或覆盖该槽。零贡献的 last 同样更新并标记完成。
- G=2 保留共同完成与共同交接原则，但交接对象是两份独立完整状态，而不是两个32-bit转换结果。字段打包、完成位图和指定编号读取按下文接口执行。
- 外部未接收时，完成槽继续占用；全部槽均被占用时，无空闲上下文可启动新事务。不额外复制结果到 FIFO，也不预留独立输出容量。外部保证合法调度，接收释放后的下一拍允许复用，见下文。
- 只提供已完成状态读取，不提供中途状态访问、换出或恢复写入口。外部SRAM存储、地址分配及后续处理不属于MAC职责。

### 上下文生命周期与读取接口（2026-11-12 已确认）

- 三个事务槽使用共同2-bit ctx_id（0/1/2合法，3非法）。G=2槽c对应ACC0[c]与ACC1[c]，G=1仅使用ACC0[c]，不支持任意跨编号配对。
- 输入携带mode、mx、ctx_id、first、last、valid。first启动空闲槽，在ACC旧值选择处取零，不在入口清空数值寄存器；last接收后禁止追加，最终写回后才完成。允许first=last=1。生命周期为空闲、累加中、结束处理中、已完成，外部接收后回到空闲。
- 正常计算采用valid-only输入。外部保证D=3重访间隔、first/last合法、模式一致及释放前不复用，由验证断言检查，不增加自动冲突调度器。所有被占用槽使用同一mode/mx，scale可逐贡献变化；所有槽释放且计算流水排空后才切换模式。
- 输出提供3-bit free/done位图。外部以i_result_ctx选择槽；o_result_valid表示该槽已完成，o_state0/1各51位，附mode/mx。外部可选择任意完成槽，不设置内部输出仲裁；保持选择时未接收的完成状态保持，改变选择则切换输出。
- o_result_valid与i_result_ready在边沿共同有效时接收并释放所选槽。G=2共同交接两路完整状态，G=1仅第一路有效。每拍可交接一个槽，释放后下一拍才允许first复用，不允许释放边沿同时复用。
- 浮点及MX字段为[50:41]=H、[40:0]=M；普通整数[44:0]=signed45状态，高6位符号扩展；G=1第二路输出置零。mode编码按P1-5设计稿。
- 不设置保存恢复维护阶段，不因此增加输入ready；正常计算采用valid-only。ACC读写周期按下文方案，前向物理边界按P1-5设计稿。

### ACC反馈周期与排空判据（2026-11-12 已确认）

- 上下文寄存器组组合读取，S1内选择旧状态并完成对阶，不增加同步读周期；S2执行45-bit加法；S3完成规格化/RNE并直接写回状态寄存器，不增加额外结果/写回级，不设置同地址写回旁路。普通整数保留三段时序，旁路浮点运算。
- 以S1结果采样为E0，S2在E1采样，S3在E2写回。同ctx下一贡献在E2之后读取新状态并完成S1，在E3采样，故最小发起间隔D=3；不得依赖E2同边沿写回的新状态供E2的S1采样使用。周期表见IP_DESIGN第9.2节（该表以MAC入口为E0）。
- MAC入口至ACC S1各模式采用相同固定延迟，功能旁路保留流水寄存器，气泡不压缩间距。入口同ctx间隔至少3拍，ACC对应间隔保持；不足三个活动上下文时由外部插入气泡，不暂停在途有效计算。前向具体级数与延迟按P1-5设计稿。
- last在S3写回边沿同时置done。若E2写回，最早E3外部接收并释放，最早E4入口复用。零贡献last同样执行。
- 排空条件为MAC入口至ACC写回之间全部计算流水valid均为0；停止供数后继续推进至最后一次写回完成。流水为空可仍有待续或已完成未接收的上下文，正常模式切换另要求全部槽释放。对外提供o_pipe_empty。
- 本节为周期设计决定，未执行RTL周期仿真或时序验证，不把三段设计视为实际频率证据。

## P1-4：共享乘法资源与跨前端重构

### 当前选定的两宽两小方案

- 每个物理乘法前端配置 **2颗 signed9×signed9 + 2颗 signed5×signed5**；整个MAC核心以16前端为基准，共32颗9×9、32颗5×5。这是本轮选定方案，替代原3颗7×5加1颗5×5配置。
- 保留外部输入转换模块提供补码系数；有符号字段符号扩展，无符号低段零扩展。FP4保持q=2x，FP8/FP16折叠有效指数低两位，BF16乘前不折叠、完整乘积后postfold；字段及权重见前文。

| 格式 | 每个完整乘积的映射 | 16前端完整乘积/拍 | K/G | 闲置资源 |
|---|---|---:|---|---|
| FP4 | signed5系数直接相乘，每前端四颗块各算一个 | 64 | 32/2 | 无 |
| FP8 | signed8系数进入9×9，每前端两个 | 32 | 16/2 | 每前端两颗5×5 |
| INT4 | signed4直接扩展，每前端四颗块各算一个 | 64 | 32/2 | 无 |
| INT8 | signed8直接进入9×9，每前端两个 | 32 | 16/2 | 每前端两颗5×5 |
| INT16 | 8+8分段，四颗9×9、两前端配对 | 8 | 8/1 | 每对四颗5×5 |
| FP16 | 折叠后8+7分段，四颗9×9、两前端配对 | 8 | 8/1 | 每对四颗5×5 |
| BF16 | signed9直接相乘，每前端仅用一颗9×9 | 16 | 16/1 | 每前端一颗9×9及两颗5×5 |

- 上表计完整元素乘积，不计部分积；是供数、流水和后级充分时的结构能力，未验证端到端吞吐。BF16不启用32乘积/拍或G=2组织；只需一组16项通路具备BF16的9位原乘积指数、乘后折叠及7位粗指数的4 bit粒度对阶能力，具体共享电路按P1-5设计稿。
- FP4单项可用signed9，INT4可用signed8，FP8/INT8可用signed16，BF16可用signed18容器。9×9物理输出18位；缩窄时只能去除已证明冗余的符号位，不截断有效数值。进入归约前按所需范围扩位。

### INT16与FP16的四部分积重构

- 两侧都按 `a=aL+2^8×aH`、`b=bL+2^8×bH` 分段。INT16低段unsigned8、高段signed8；折叠后的FP16低段unsigned8、高段signed7。低段前补零进入signed9，高段符号扩展进入signed9。
- `p00=aL×bL`、`p01=aL×bH`、`p10=aH×bL`、`p11=aH×bH`。前端A的两颗宽块计算p00、p01，前端B计算p10、p11；精确重构 `P=p00+2^8×(p01+p10)+2^16×p11`。
- 各部分积可保留18位乘法输出，交叉和signed18足够覆盖上述分段实际范围；INT16完整重构使用signed32容器，FP16使用signed30容器。移位前扩展至足够宽度，不能在窄部分积容器内移位并丢弃高位。
- 每个完整乘积四个部分积，按二输入加法口径三次合并；不要求实现为三个独立进位加法器。本轮采用34-bit临时域的两层重构，路由及寄存器见P1-5。宽元素的部分积重构与不同元素归约在数值上分开，FP16须先精确重构再逐项截断对阶。
- 16前端组成八对，每拍可同时发射八组完整乘积的部分积；不表示一拍完成重构，也不要求同一元素分两拍乘法。每个完整浮点乘积只做一次源指数求和，不为部分积重复求指数。
- MXFP8、MXFP4、MXINT8分别复用对应普通格式的元素乘法映射；scale及FP4的-2、MXINT8的-12权重按P1-3处理。MXINT8采用K=16、G=2，块供数与scale关联按P1-3执行。
- 当前每前端位宽乘积之和为212，原配置为130；仅作为乘法资源粗略指标，不含重构、路由、寄存器、布线等，不是面积测量或精确面积比例。当前无综合、时序或PPA结论。

### 入口转换与前端接口（2026-11-12 已确认）

#### 转换器边界

- 独立输入转换器只实现一份模块逻辑：输入一个16-bit raw word、源格式和valid，输出一个22-bit字段bundle及valid。
- 转换器不例化在MAC内，也不与MAC端口物理连接。MAC入口是乘法前端；MAC测试直接使用转换后的字段向量，不重复分类原始编码。
- 一个raw word的打包约定：FP4/INT4为4×4bit，按`g0p0,g0p1,g1p0,g1p1`从低到高；FP8/INT8为2×8bit，低字节g0、高字节g1；BF16/FP16/INT16为1×16bit的g0。尾段补零由外部完成，前端不设逐元素valid。
- 转换器完成分类、特殊值映射、subnormal保留、FP8/FP16折叠、补码系数构造、FP4的`q=2x`和INT4符号扩展；不生成、不应用MX scale。scale随MAC事务meta传递。

#### 22-bit字段bundle

每个前端每侧一个22-bit bundle；未用高位为0。字段布局如下：

| 模式 | 布局 |
|---|---|
| FP8 | `[10:0]={Q0,M0}`，`[21:11]={Q1,M1}` |
| FP4 | `[4:0]=g0p0`，`[9:5]=g0p1`，`[14:10]=g1p0`，`[19:15]=g1p1` |
| INT4 | 同FP4，q符号扩展到5bit |
| INT8 | `[7:0]=g0`，`[15:8]=g1` |
| BF16 | `[16:0]={E,m}` |
| FP16 | `[17:0]={Q,M}` |
| INT16 | `[15:0]=q` |

FP8的E4M3/E5M2在转换器中统一为`M/Q`，MAC只使用一种FP8 mode；E4M3×E5M2与E5M2×E4M3通过交换两侧fmt支持，不增加MAC内格式标签。

#### 16前端group与乘法块映射

- FP4/INT4：W0、S0固定g0，W1、S1固定g1；每前端4个乘积，每group 2个。
- FP8/INT8：W0固定g0，W1固定g1；每前端2个乘积；S0、S1空闲。
- BF16：只用W0，固定g0；W1、S0、S1空闲；保持一组dot16，不启用32乘积/拍。
- FP16/INT16：两前端配成8对，四颗W同拍形成四部分积；W0/W1在该模式下不再表示group1，S0、S1空闲。低段unsigned8零扩展，高段FP16 signed7、INT16 signed8符号扩展；不使用两拍phase。

16前端合计完整乘积/拍与P1-3的K/G一致：FP4/INT4为64、32/2；FP8/INT8为32、16/2；BF16为16、16/1；FP16/INT16为8、8/1。

#### 归约树

- 物理资源为 **2棵16输入、32-bit输入、36-bit输出的加法树，加1个41-bit最终加法器**。不使用38-bit宽树，也不使用4棵树的两级方案。
- TreeA/TreeB的用途：

| 模式 | TreeA | TreeB | 最终加法 | N |
|---|---|---|---|---|
| FP4 | packed `p0/p2` | packed `p1/p3` | A+B，切分并修正g0 | g0 14，g1 14 |
| INT4 | packed `p0/p2` | packed `p1/p3` | A+B，切分并修正g0 | g0 12，g1 12 |
| FP8 | g0对阶系数 | g1对阶系数 | 无 | 36/36 |
| INT8 | g0乘积 | g1乘积 | 无 | 19/19 |
| BF16 | g0对阶系数 | 空闲 | 无 | 36 |
| INT16 | g0完整乘积 | 空闲 | 无 | 34 |
| FP16 | `CL`低19位 | `CH`高19位 | `low+(high<<19)` | 41 |

- FP8/BF16/FP16的每组非零MAX及随后逐项对齐/截断在树前完成；FP4/INT4/INT8/INT16无MAX/对齐，直接进入树或先packing。
- FP16的38-bit对阶系数拆为`CL=C[18:0]`（unsigned19）和`CH=C[37:19]`（signed19），满足`C=CL+2^19×CH`；TreeA/TreeB分别归约8个limb，最终`N=ΣCL+2^19×ΣCH`。ΣCL为unsigned22、ΣCH为signed22；输入分别零扩展/符号扩展到32位，每树其余8项置零。最终低和零扩展到41位，高和符号扩展到41位再左移19位，低limb进位由最终加法器吸收。
- FP4/INT4采用offset-binary packing，使两棵树同时计算两个group。记`p0=W0(g0)`、`p1=S0(g0)`、`p2=W1(g1)`、`p3=S1(g1)`：

```text
L=9（FP4）或8（INT4），W=L+5，β=2^(L-1)
p0o=p0^β，p1o=p1^β
A_i={p2_i,5'b0,p0o_i}
B_i={p3_i,5'b0,p1o_i}
S=ΣA_i+ΣB_i
g0=signed(S[W-1:0]^2^(W-1))
g1=signed(S[W+L+4:W])
```

低场加β后为非负数，32项偏置总和为`32β=2^(W-1)`，由最终低场MSB取反精确消除；中间5个0位是求和增长位。packed word宽度为`L+W`，按高场`p2/p3`的符号扩展到32-bit树输入；树输出36-bit。不能直接用补码`{p2,5'b0,p0}`，也不能只向guard位做符号扩展，否则负乘积的偏移/借位会污染高场。

| 模式 | L | β | W | packed word | Tree输出 | 最终S | g0/g1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| FP4 | 9 | 256 | 14 | 23 | 27 | 28 | 14/14 |
| INT4 | 8 | 128 | 13 | 21 | 25 | 26 | 13/13（N12） |

- BF16的W0在完整signed18乘积后执行postfold：`r=T mod 4`、`Q=T>>2`、`P'=signext21(P)<<r`；`P==0`时强制`P'=0,Q=0`。该步骤在局部MAX前，属于乘法功能级；物理寄存器边界未定。

#### 归约输出接口

每个group输出一条逻辑记录：

```text
N[40:0]        signed，局部精确和，符号扩展到41位
e_loc[9:0]     signed，不含MX scale
h[8:0]         signed，h=sA+sB；非MX为0
group
ctx_id[CTX_W-1:0]
first, last, valid
```

- N的逻辑宽度：FP4 14、INT4 12、FP8 36、INT8 19、BF16 36、FP16 41、INT16 34；统一符号扩展到41位后送MX/ACC。普通INT路径绕过MX；MXINT8使用`e_loc=-12`与h进入浮点路径。
- `e_loc`按P1-3表取值，不含h；MX级计算`e=e_loc+h`，只加一次。`h`用signed9，`e_loc/e`用signed10。
- `N=0`仍为有效贡献，`last`仍有效；零贡献规范为`N=e_loc=h=0`。零乘积判定使用`P!=0`，不能用`T/Q==0`。
- G=2时FP4/INT4的最终packed加法切出g0/g1两条记录；FP8/INT8两棵树各一条；BF16/INT16/FP16一条。两条记录固定送两条ACC通路，不跨group合并。CTX_W=2及first/last、完成读取握手按P1-3执行，级间记录按IP_DESIGN第9.1节。
- 旧PSUM的56-bit打包不继承；物理上是一条记录、两条记录槽还是宽容器，待归约/MX边界流水设计。

上述是接口与归约结构选择；RTL、仿真、综合、PPA和正式数值实验均未开始。

| FP4 完整乘积/拍 | 64，四颗块分别计算 qA×qB | 64，四颗块分别计算 qA×qB |
| INT4 完整乘积/拍 | 64 | 64 |
| INT8 完整乘积/拍 | 16，每前端四个 4 位分段部分积重构一个乘积 | 32，两颗 9×9 各计算一个乘积 |
| INT16 完整乘积/拍 | 4，四前端协同提供 16 个 4 位分段部分积 | 8，每个乘积需要四个 8 位分段部分积 |
| FP16 完整乘积/拍 | 16，每前端按 6+6 分段，四项重构 | 16，每前端按 6+6 分段，四项重构 |
| BF16 完整乘积/拍 | 16，原生 signed9 系数按 5+4 分段，四项重构 | 32，两颗 9×9 各计算一个乘积 |

- 上表是所列映射在供数、重构及流水充分时的前端吞吐，不是端到端 MAC 已验证吞吐，也不冻结其他格式的最终吞吐目标。两种基线映射的 INT8:INT16 比例均为 4:1。
- 补码分段的低段按无符号解释，最高段按有符号解释，分别零扩展或符号扩展后进入小乘法块。例如 `a=aL+2^r×aH`，则 `ab=aL×bL+2^r×(aL×bH+aH×bL)+2^(2r)×aH×bH`。重构必须在足够宽的有符号域中执行。
- 方案 A 的 INT16 按 4 个 4 位段展开；四前端的部分积经过定权重构形成一个完整元素乘积。FP16 的 unsigned6 低段可由 signed7 端口精确容纳，BF16 的 unsigned5 低段也可容纳。
- 方案 B 的 INT16 保留两种待比较组织：两前端配对、每拍同时生成四项后重构；或单前端分两拍生成四项、不同前端错开发射。后者要实现每拍接收 8 对新 INT16 输入，需明确 phase、操作数保持、调度及停顿协议，不能接收超过持续计算能力的数据。
- 方案 B 的 INT16 unsigned8 低段前补零进入 signed9 端口，高段符号扩展。宽乘积重构与不同元素沿归约维度求和在数学上分开定义，是否融合实现尚未决定。
- 两历史方案在表列 FP8 两路映射下均闲置两颗块；这是这些映射的选择，不是 FP4:FP8 吞吐比为 2:1 所强制的资源下界。方案 B 的 INT8/BF16 及上述 INT16 映射不使用两颗 7×7 块。
- 7×7、9×9 的位宽乘积之和不能作为完整面积估计。需计入部分积重构、路由、寄存器、符号处理与布线；实际频率、面积、功耗和后级持续承接能力均未验证，不记录未经综合支持的面积增减比例。

## P1-5：完整设计稿的实施细节（2026-11-12 授权补齐，待整体审核）

用户授权按合理方案补齐剩余设计，再整体审核。本节记录本轮设计稿选择，不将其表述为用户逐项审核通过或RTL验证结论。完整正文以[IP_DESIGN](../design/new_architecture/IP_DESIGN.md)为主，以下仅保留关键选择摘要。

- 功能章节按转换、乘法、MAX/对阶、归约、MX、ACC、完成读取编排。MAC边界仍为ACC状态，未扩大到输出转换或保存恢复。
- MAC mode为3-bit：0 FP4、1 FP8、2 BF16、3 FP16、4 INT4、5 INT8、6 INT16、7非法；mx仅允许FP4/FP8/INT8。独立转换器fmt为0 FP4、1 E4M3FN、2 E5M2、3 BF16、4 FP16、5 INT4、6 INT8、7 INT16。转换器采用一级寄存输出。
- MAC A/B端口各16×22位；FP16/INT16每个元素只从偶槽2j取得完整bundle，内部广播给前端2j/2j+1，奇槽忽略；指数仅由偶槽计算一次。四部分积采用34-bit临时域两层重构，再精确缩窄至合法完整乘积容器。
- scale入口每侧16位，低/高字节分别g0/g1原始E8M0；R_IN生成每组signed9 h，MX级只加一次。公共metadata为mode/mx/ctx/first/last（8位）及valid，group以物理槽索引表示。
- 两棵16输入7-bit非零MAX树；对阶器共8条38-bit与24条32-bit，前8条宽路复用FP8/BF16的32-bit符号扩展数据及FP16，余下对应窄路。距离9位，超宽右移符号填充，不统一清零。
- 两棵32→36-bit平衡归约树各在第2层后寄存34-bit部分和、第4层后寄存36-bit和，最终41-bit重构后寄存。FP16低和unsigned22零扩展、高和signed22符号扩展后移19位。FP4/INT4 packing合同不变。
- 核心物理顺序为R_IN→R_MUL→R_PROD→R_MAX→R_ALIGN→R_TREE_LO→R_TREE_HI→R_SUM→R_MX→R_ACC1→R_ACC2→状态写回。入口E0接收，E11写回；所有模式11个时钟间隔相同，last最早E12被外部接收、E13复用。ACC仍组合读、三段末直接写回，D=3不变。
- 低有效同步复位清控制与valid，数值寄存器无需清零；复位中止所有事务。所选槽非DONE或读取编号3时，valid及输出字段为0；有效计算ctx=3仍非法。o_pipe_empty表示全部11个计算流水valid为0，不等价于全部槽空闲。
- 生命周期编码FREE/ACTIVE/CLOSING/DONE为00/01/10/11，批次mode/mx锁存且在占用期间不变。完成后原槽保持、指定读取释放，与先前协议一致。
- 数值算术形式已确定；乘法器内部Booth门级展开、标准单元映射等可由Verilog运算与综合决定，不需要另设功能选型。尚需用户整体审核、RTL与时序验证；统一精度阈值继续独立待定。

## 实现与验证方式

- 新实现使用 Verilog；SystemVerilog 基线仅用于功能参考和验证。
- 入口转换与乘法前端分别独立实现和测试；转换器不与MAC物理连接，MAC测试使用转换后的字段向量。是否增加集成测试由后续需要决定。该开发方式不预先规定最终寄存器边界或流水结构；微架构变化时相应调整。
- 本机只进行编译和简单仿真；详细仿真、综合和时序分析在服务器完成。保密报告仅提供结果摘要。
- 独立参考模型保持独立，不复用 DUT 算法来替代验证依据。

## 设计审核与验证边界

新架构的数值合同、资源结构、事务生命周期及D=3已经讨论确认；前向连接、编码、寄存器与复位细节已按P1-5授权补齐，完整IP设计稿等待用户整体审核，不自动开始RTL。

仍需实际验证的是转换器与完整输入链、位级RTL等价性、周期/吞吐、16384项覆盖，以及综合、时序和PPA；统一数值精度验收阈值尚未确认。设计完整不等于上述验证完成。历史A/B方案、旧Q2.34接口和旧基线测试均不覆盖当前新架构合同。
