# 项目状态

状态更新日期：2026-11-12；下文旧基线证据日期仍为2026-10-31。

本文区分新架构的设计与数值实验证据，以及旧 SystemVerilog dot16/Q2.34 基线的历史实现与验证状态。新架构已确认约束、仍未冻结的选择见[已确认约束](decisions.md)；旧设计的数值合同、接口和流水结构不默认继承。

## 新架构设计与证据

- 共享乘法资源映射、局部截断归约、逐份贡献加后RNE40、多上下文交错及有限工作位补码数据通路已选定；位级数据通路为2位真实低位＋sticky、45位共享加法器、三段流水（D=3）、两条累加通路各3组上下文。位级模型与T0–T5检查已实现并在本地通过；RTL、共仿、综合与时序未开始；累加器恢复协议与周期级微架构仍未完成。
- 入口转换、22-bit字段bundle、16前端group/块映射、2棵16输入树加41-bit最终加法器的归约结构、FP16 19/19 limb重构、FP4/INT4 offset-binary packing及N41/e_loc/h输出接口已确认；算术模型只做过Python只读算术核对（随机与枚举），RTL、共仿、综合和PPA未开始。
- 已有[局部对阶实验](../experiments/README.md)和[累加精度实验](../experiments/accumulation_precision.md)的数值模型与运行结果。局部实验用后续精确累计隔离局部损失；累加实验用精确dyadic相加后RNE评价状态精度。二者的配置、覆盖范围及结论边界见各自说明与[已确认约束](decisions.md)，不能替代有限工作位电路或全部合法输入域的验证。
- 新架构尚无已交接的RTL实现、端到端仿真、综合、时序或PPA证据；现有Verilog文件仍是旧基线的未完成改写。旧基线历史测试不作为新架构验证结果。
- [新架构IP设计文档](../design/new_architecture/IP_DESIGN.md)已写入已确认的入口转换、前端接口和归约结构；累加器、最终转换、RTL及物理流水等其余内容仍待补。原有IP与RTL设计文档仍描述旧基线。

后续架构调整和任务顺序由用户确定；本次状态更新未重跑正式测试或实验，入口/归约部分只做了只读算术核对。

## 旧基线实现与证据缺口

- 当前完整链路由 testbench 连接；没有生产顶层封装、最终 FP32/其他目标格式转换器或结果端 ready。
- MX 非零贡献的数学指数 E 超出 1…254 仍是暂缓定义域。仿真断言用于拒绝该输入，不代表综合后的恢复策略。
- ACC 写回已定义 FTZ/Inf；这与 MX 输入越界边界不同，不能混为一种策略。
- PSUM 仿真采用 DesignWare 功能替身；本次没有真实库验证、综合、STA、面积、功耗或布局结果。
- 暂未形成旧基线 Q2.34 语义下的完整精度与 PPA 权衡评估。早期 `hwacc-v1` 实验与旧基线实现的系数、指数及舍入过程存在差异，不能直接把旧位宽结论当作旧基线 RTL 的精度保证。
- 图稿和章节已有草稿，但图中的输出保持槽等描述仍需在工程实现完善后复核。
